Invite teammates and manage their access from the dashboard.

## Invite a teammate

<Tabs sync={false}>
  <Tab title="Dashboard">
    1. Open [**Settings → Members**](https://app.axilio.ai/dashboard).
    2. Click **Invite member**.
    3. Enter the email address and choose **Admin**, **Member**, or **Viewer**.
    4. Click **Send invitation**.
  </Tab>

  <Tab title="CLI">
    The CLI does not currently manage organization members. Use the dashboard.
  </Tab>

  <Tab title="Python SDK">
    The current Python SDK does not expose organization invitations. Use the
    dashboard.
  </Tab>

  <Tab title="Go SDK">
    The current Go SDK does not expose organization invitations. Use the dashboard.
  </Tab>
</Tabs>

## List members

<Tabs sync={false}>
  <Tab title="Dashboard">
    1. Open **Settings → Members**.
    2. Search by name, email, or role.
    3. Sort the table by **Name**, **Email**, **Role**, **Status**, or join date.
  </Tab>

  <Tab title="CLI">
    The CLI does not currently list organization members. Use the dashboard.
  </Tab>

  <Tab title="Python SDK">
    The current Python SDK does not expose organization-member listing. Use the
    dashboard.
  </Tab>

  <Tab title="Go SDK">
    The current Go SDK does not expose organization-member listing. Use the dashboard.
  </Tab>
</Tabs>

## Change a role or remove someone

<Tabs sync={false}>
  <Tab title="Dashboard">
    1. Open **Settings → Members**.
    2. Select the checkbox beside one or more members.
    3. Choose a new value from **Set role…** to change their roles, or click
       **Remove** to remove them.
    4. Confirm the removal when prompted.
  </Tab>

  <Tab title="CLI">
    The CLI does not currently change roles or remove members. Use the dashboard.
  </Tab>

  <Tab title="Python SDK">
    The current Python SDK does not expose role changes or member removal. Use the
    dashboard.
  </Tab>

  <Tab title="Go SDK">
    The current Go SDK does not expose role changes or member removal. Use the
    dashboard.
  </Tab>
</Tabs>
