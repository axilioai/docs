title: "Members and invitations"
sidebarTitle: "Members"
description: "Manage organization membership in the dashboard and read member or invitation summaries through the public API."
---

Member and invitation changes are dashboard-only. The public API exposes
read-only summaries so an integration can audit access without changing the
organization that issued its key.

## Manage access

1. Open [**Settings → Members**](https://app.axilio.ai/dashboard/axilio/settings/members) after choosing
   your organization.
2. Click **Invite member** to send an invitation.
3. Use the member row to change a role or remove access.
4. Use the invitations list to review or cancel outstanding invitations.

The CLI, Python SDK, Go SDK, and public REST API cannot invite, change, or remove
members.

The CLI also has no commands for listing members or invitations. Use the
dashboard or the read-only public API for those operations.

## List members

<Tabs sync={false}>
  <Tab title="Dashboard">
    Open [**Settings → Members**](https://app.axilio.ai/dashboard/axilio/settings/members)
    after selecting the organization. Accepted members appear as active rows
    with their name, email address, role, and join date.

    The dashboard page is available to organization admins.
  </Tab>

  <Tab title="Python SDK">
    ```python
    members = client.raw.organization.list_members()

    for member in members.members or []:
        print(member.email, member.role, member.joined_at)
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    members, err := api.Organization.ListMembers(ctx)
    if err != nil {
        log.Fatal(err)
    }
    for _, member := range members.Members {
        fmt.Println(member.Email, member.Role, member.JoinedAt)
    }
    ```
  </Tab>

  <Tab title="REST API">
    REST API References:

    - [**List the organization's members**](/api-reference/rest/organization/list-the-organizations-members): `GET /organization/members`

    ```bash
    curl --silent --show-error --fail-with-body \
      --url https://api.axilio.ai/api/v1/organization/members \
      --header "X-Axilio-Api-Key: $AXILIO_API_KEY"
    ```
  </Tab>
</Tabs>

## List outstanding invitations

<Tabs sync={false}>
  <Tab title="Dashboard">
    Open [**Settings → Members**](https://app.axilio.ai/dashboard/axilio/settings/members)
    after selecting the organization. Pending invitations appear in the same
    table as accepted members, with their requested role and invitation date.

    The dashboard page is available to organization admins.
  </Tab>

  <Tab title="Python SDK">
    ```python
    invitations = client.raw.organization.list_invitations()

    for invitation in invitations.invitations or []:
        print(invitation.email, invitation.role, invitation.invited_at)
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    invitations, err := api.Organization.ListInvitations(ctx)
    if err != nil {
        log.Fatal(err)
    }
    ```
  </Tab>

  <Tab title="REST API">
    REST API References:

    - [**List pending invitations**](/api-reference/rest/organization/list-pending-invitations): `GET /organization/invitations`

    ```bash
    curl --silent --show-error --fail-with-body \
      --url https://api.axilio.ai/api/v1/organization/invitations \
      --header "X-Axilio-Api-Key: $AXILIO_API_KEY"
    ```
  </Tab>
</Tabs>

The public members endpoint requires the viewer role or higher. The public
invitations endpoint requires an organization admin. The dashboard page is
admin-only for both lists.
