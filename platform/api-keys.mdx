API keys authenticate the CLI and SDKs. Each key belongs to your organization
and starts with `axl_`.

## Create a key

<Tabs sync={false}>
  <Tab title="Dashboard">
    1. Open [**Settings → API Keys**](https://app.axilio.ai/dashboard).
    2. Click **Create Key**.
    3. Enter a name and click **Create**.
    4. Copy the secret before clicking **Done**.
  </Tab>

  <Tab title="CLI">
    ```bash
    axilio api-keys create ci-bot
    ```

    Add `-o json` to return the ID, name, full secret, and creation time as JSON.
  </Tab>

  <Tab title="Python SDK">
    ```python
    key = client.api_keys.create(name="ci-bot")
    print(key.key_value)
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    key, err := api.APIKeys.Create(ctx, &platformgo.APIKeyCreateRequest{
        Name: "ci-bot",
    })
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(key.KeyValue)
    ```
  </Tab>
</Tabs>

<Warning>
  The full secret is shown once, immediately after creation. Save it somewhere
  safe; you can't retrieve it later.
</Warning>

## List keys

<Tabs sync={false}>
  <Tab title="Dashboard">
    1. Open **Settings → API Keys**.
    2. Search by name or masked key value.
    3. Use **Created by** and **Created** to filter the list.
  </Tab>

  <Tab title="CLI">
    ```bash
    axilio api-keys list
    ```

    Add `-o json` for structured output. Full secrets are never returned here.
  </Tab>

  <Tab title="Python SDK">
    ```python
    keys = client.api_keys.list()

    for key in keys.api_keys or []:
        print(key.id, key.name, key.key_preview)
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    keys, err := api.APIKeys.List(ctx, &platformgo.APIKeysListRequest{})
    if err != nil {
        log.Fatal(err)
    }

    for _, key := range keys.APIKeys {
        fmt.Println(key.ID, key.Name, key.KeyPreview)
    }
    ```
  </Tab>
</Tabs>

## Delete or replace a key

There is no regenerate operation. Delete the old key and create a replacement:

<Tabs sync={false}>
  <Tab title="Dashboard">
    1. Open **Settings → API Keys**.
    2. Select the checkbox beside the old key, click **Delete**, and confirm.
    3. Click **Create Key** to create and copy its replacement.
  </Tab>

  <Tab title="CLI">
    ```bash
    axilio api-keys delete key_123 --yes
    axilio api-keys create replacement
    ```
  </Tab>

  <Tab title="Python SDK">
    ```python
    client.api_keys.delete("key_123")
    replacement = client.api_keys.create(name="replacement")
    print(replacement.key_value)
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    _, err := api.APIKeys.Delete(ctx, &platformgo.APIKeysDeleteRequest{
        KeyID: "key_123",
    })
    if err != nil {
        log.Fatal(err)
    }

    replacement, err := api.APIKeys.Create(ctx, &platformgo.APIKeyCreateRequest{
        Name: "replacement",
    })
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(replacement.KeyValue)
    ```
  </Tab>
</Tabs>
