API keys authenticate the CLI, SDKs, and REST API. Each key belongs to your
organization and starts with `axl_`.

You need the **Admin** role to create, list, or delete API keys.

## Create a key

<Tabs sync={false}>
  <Tab title="Dashboard">
    1. Open [**Settings → API Keys**](https://app.axilio.ai/dashboard).
    2. Click **Create Key**.
    3. Enter a name and click **Create**.
    4. Copy the secret before clicking **Done**.
  </Tab>

  <Tab title="CLI">
    ```bash
    axilio api-keys create ci-bot
    ```

    Add `-o json` to return the ID, name, full secret, and creation time as JSON.
  </Tab>

  <Tab title="Python SDK">
    ```python
    key = client.api_keys.create(name="ci-bot")
    print(key.key_value)
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    key, err := api.APIKeys.Create(ctx, &platformgo.APIKeyCreateRequest{
        Name: "ci-bot",
    })
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(key.KeyValue)
    ```
  </Tab>

  <Tab title="REST API">
    ```bash
    curl --request POST \
      --url https://api.axilio.ai/api/v1/api-keys \
      --header "X-Axilio-Api-Key: $AXILIO_API_KEY" \
      --header "Content-Type: application/json" \
      --data '{"name":"ci-bot"}'
    ```
  </Tab>
</Tabs>

<Warning>
  The full secret is shown once, immediately after creation. Save it somewhere
  safe; you can't retrieve it later.
</Warning>

## List keys

<Tabs sync={false}>
  <Tab title="Dashboard">
    1. Open **Settings → API Keys**.
    2. Search by name or masked key value.
    3. Use **Created by** and **Created** to filter the list.
  </Tab>

  <Tab title="CLI">
    ```bash
    axilio api-keys list
    ```

    Add `-o json` for structured output. Full secrets are never returned here.
  </Tab>

  <Tab title="Python SDK">
    ```python
    keys = client.api_keys.list()

    for key in keys.api_keys or []:
        print(key.id, key.name, key.key_preview)
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    keys, err := api.APIKeys.List(ctx, &platformgo.APIKeysListRequest{})
    if err != nil {
        log.Fatal(err)
    }

    for _, key := range keys.APIKeys {
        fmt.Println(key.ID, key.Name, key.KeyPreview)
    }
    ```
  </Tab>

  <Tab title="REST API">
    ```bash
    curl --request GET \
      --url https://api.axilio.ai/api/v1/api-keys \
      --header "X-Axilio-Api-Key: $AXILIO_API_KEY"
    ```
  </Tab>
</Tabs>

## Delete or replace a key

There is no regenerate operation. Create and save the replacement first, move
your consumers to it, then delete the old key. Use the old key's UUID from the
list response as `OLD_KEY_ID`:

<Tabs sync={false}>
  <Tab title="Dashboard">
    1. Open **Settings → API Keys**.
    2. Click **Create Key**, then copy and store the replacement secret.
    3. Update every consumer and verify it can authenticate with the new key.
    4. Select the checkbox beside the old key, click **Delete**, and confirm.
  </Tab>

  <Tab title="CLI">
    ```bash
    axilio api-keys create replacement
    # Save the new secret, update consumers, and verify them before continuing.
    axilio api-keys delete "$OLD_KEY_ID" --yes
    ```
  </Tab>

  <Tab title="Python SDK">
    ```python
    replacement = client.api_keys.create(name="replacement")
    print(replacement.key_value)

    # Save the new secret, update consumers, and verify them before deleting.
    client.api_keys.delete(old_key_id)
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    replacement, err := api.APIKeys.Create(ctx, &platformgo.APIKeyCreateRequest{
        Name: "replacement",
    })
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(replacement.KeyValue)

    // Save the new secret, update consumers, and verify them before deleting.
    _, err = api.APIKeys.Delete(ctx, &platformgo.APIKeysDeleteRequest{
        KeyID: oldKeyID,
    })
    if err != nil {
        log.Fatal(err)
    }
    ```
  </Tab>

  <Tab title="REST API">
    ```bash
    REPLACEMENT=$(curl --silent --show-error --fail-with-body --request POST \
      --url https://api.axilio.ai/api/v1/api-keys \
      --header "X-Axilio-Api-Key: $AXILIO_API_KEY" \
      --header "Content-Type: application/json" \
      --data '{"name":"replacement"}')
    printf '%s\n' "$REPLACEMENT" | jq

    # Save the new secret, update consumers, and verify them before continuing.
    curl --request DELETE \
      --url "https://api.axilio.ai/api/v1/api-keys/$OLD_KEY_ID" \
      --header "X-Axilio-Api-Key: $AXILIO_API_KEY"
    ```
  </Tab>
</Tabs>
