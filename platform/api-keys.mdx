API keys authenticate the CLI, SDKs, and REST API. Each key belongs to one
organization and starts with `axl_`.

Listing, creating, and deleting API keys requires an organization admin.

## Create a key

<Tabs sync={false}>
  <Tab title="Dashboard">
    1. Open [**API Keys**](https://app.axilio.ai/dashboard) after choosing your organization.
    2. Click **Create Key**.
    3. Enter a name and create the key.
    4. Copy the secret before closing the dialog.
  </Tab>

  <Tab title="CLI">
    ```bash
    axilio api-keys create ci-bot
    ```

    Add `-o json` for structured output.
  </Tab>

  <Tab title="Python SDK">
    ```python
    key = client.api_keys.create(name="ci-bot")
    print(key.id, key.key_value)
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    key, err := api.APIKeys.Create(ctx, &platformgo.APIKeyCreateRequest{
        Name: "ci-bot",
    })
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(key.ID, key.KeyValue)
    ```
  </Tab>

  <Tab title="REST API">
    ```bash
    curl --silent --show-error --fail-with-body \
      --request POST \
      --url https://api.axilio.ai/api/v1/api-keys \
      --header "X-Axilio-Api-Key: $AXILIO_API_KEY" \
      --header "Content-Type: application/json" \
      --data '{"name":"ci-bot"}'
    ```
  </Tab>
</Tabs>

<Warning>
  The full `key_value` is returned once, when the key is created. Store it in a
  secret manager. List operations return only a masked preview.
</Warning>

## List keys

<Tabs sync={false}>
  <Tab title="Dashboard">
    Open **API Keys** to search by name or preview and inspect creator,
    last-used time, and creation time.
  </Tab>

  <Tab title="CLI">
    ```bash
    axilio api-keys list
    ```
  </Tab>

  <Tab title="Python SDK">
    ```python
    keys = client.api_keys.list(limit=50)

    for key in keys.api_keys or []:
        print(key.id, key.name, key.key_preview, key.last_used_at)
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    keys, err := api.APIKeys.List(ctx, &platformgo.APIKeysListRequest{
        Limit: platformgo.Int64(50),
    })
    ```
  </Tab>

  <Tab title="REST API">
    Use `GET /api/v1/api-keys`.
  </Tab>
</Tabs>

## Replace or delete a key

There is no regenerate operation. Create the replacement, update and verify
every consumer, then delete the old key.

<Tabs sync={false}>
  <Tab title="Dashboard">
    1. Create and save the replacement key.
    2. Update every consumer and verify it can authenticate.
    3. Select the old key, click **Delete**, and confirm.
  </Tab>

  <Tab title="CLI">
    ```bash
    axilio api-keys create replacement
    # Save the secret and move consumers before continuing.
    axilio api-keys delete key_123 --yes
    ```
  </Tab>

  <Tab title="Python SDK">
    ```python
    replacement = client.api_keys.create(name="replacement")
    print(replacement.key_value)

    # Move and verify consumers before deleting the old key.
    client.api_keys.delete("key_123")
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    replacement, err := api.APIKeys.Create(ctx, &platformgo.APIKeyCreateRequest{
        Name: "replacement",
    })
    if err != nil {
        log.Fatal(err)
    }

    _, err = api.APIKeys.Delete(ctx, &platformgo.APIKeysDeleteRequest{
        KeyID: "key_123",
    })
    ```
  </Tab>

  <Tab title="REST API">
    Create the replacement with `POST /api/v1/api-keys`. Delete the old key
    with `DELETE /api/v1/api-keys/{key_id}` after migration.
  </Tab>
</Tabs>

Deleting a key takes effect for subsequent requests. Do not delete the
credential currently running an unattended migration until the replacement is
confirmed.
