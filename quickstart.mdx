In a few minutes, you will get a real Android phone and open **Settings**. The
SDK paths also save its current screen.

## Before you start

- **An Axilio account** — create an API key in the
  [dashboard](https://app.axilio.ai/dashboard) if you will use a client. See
  [Authentication](/authentication).
- **A dedicated phone** — rent one from **Phones** in the dashboard.
  Copy its `phone_id`; the examples use `ph_123` as a placeholder.
- **One interface** — the Axilio dashboard, CLI, Python 3.10 or newer, or Go.

## 1. Install a client

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    brew install axilioai/tap/axilio
    ```

    On Linux, use `curl -fsSL https://axilio.ai/install.sh | sh`.
  </Tab>

  <Tab title="Python SDK">
    ```bash
    pip install axilio
    ```
  </Tab>

  <Tab title="Go SDK">
    ```bash
    mkdir axilio-quickstart
    cd axilio-quickstart
    go mod init axilio-quickstart
    go get github.com/axilioai/platform-go@latest
    ```
  </Tab>
</Tabs>

The dashboard requires no installation. Use it for a manual first session, or
install a client when you want repeatable automation.

## 2. Add your API key

Skip this step when you use only the dashboard.

```bash
export AXILIO_API_KEY=axl_your_key_here
```

## 3. Control a phone

<Tabs sync={false}>
  <Tab title="Dashboard">
    1. Open [**Sessions**](https://app.axilio.ai/dashboard).
    2. Click **Allocate A Phone** and select your dedicated phone.
    3. Open the active session and click the phone screen to focus it.
    4. Open **Settings** on the phone.
    5. Return to **Sessions** and click **Release** when you finish.

    This is the manual path. It does not create the local `screen.png` used by
    the SDK examples.
  </Tab>

  <Tab title="CLI">
    The current CLI release still targets the pre-`0.72` session endpoints, so
    it cannot complete this quickstart against the current API. Use an SDK until
    the CLI is updated.
  </Tab>

  <Tab title="Python SDK">
    Save as `quickstart.py`:

    ```python
    from axilio.platform import Client

    client = Client()

    with client.session("android", phone_id="ph_123") as driver:
        with open("screen.png", "wb") as output:
            output.write(driver.screenshot())

        driver.find(query="the Settings icon").tap()
    ```

    ```bash
    python quickstart.py
    ```
  </Tab>

  <Tab title="Go SDK">
    Save as `main.go`:

    ```go
    package main

    import (
        "context"
        "errors"
        "log"
        "os"

        platformgo "github.com/axilioai/platform-go"
        "github.com/axilioai/platform-go/client"
        "github.com/axilioai/platform-go/drivers/mobile"
        "github.com/axilioai/platform-go/option"
    )

    func main() {
        if err := run(context.Background()); err != nil {
            log.Fatal(err)
        }
    }

    func run(ctx context.Context) error {
        api := client.NewClient(
            option.WithBaseURL("https://api.axilio.ai/api/v1"),
            option.WithAPIKey(os.Getenv("AXILIO_API_KEY")),
        )

        allocation, err := api.Phones.Allocate(ctx, &platformgo.PhoneAllocateRequest{
            PhoneType: platformgo.PhoneAllocateRequestPhoneTypeAndroid,
            PhoneID:   platformgo.String("ph_123"),
        })
        if err != nil {
            return err
        }
        defer func() {
            if _, err := api.Phones.Deallocate(ctx, &platformgo.PhonesDeallocateRequest{
                PhoneID: allocation.PhoneID,
            }); err != nil {
                log.Printf("release phone: %v", err)
            }
        }()

        if allocation.ControlURL == nil {
            return errors.New("allocation returned no control URL")
        }
        driver := mobile.ConnectRemote(*allocation.ControlURL)
        defer driver.Close()

        screenshot, err := driver.Screenshot()
        if err != nil {
            return err
        }
        if err := os.WriteFile("screen.png", screenshot, 0o600); err != nil {
            return err
        }

        settings, err := driver.Find("the Settings icon")
        if err != nil {
            return err
        }
        if err := settings.Tap(); err != nil {
            return err
        }

        return nil
    }
    ```

    ```bash
    go run .
    ```
  </Tab>
</Tabs>

REST can allocate and release a phone, but screen capture, find, and tap use the
device-control WebSocket. Use an SDK for this complete journey until the CLI is
updated. See
the [REST API reference](/api-reference/overview) for control-plane operations.

That's it—you opened a session on a real phone, controlled it, and released the
session. The SDK examples also saved its screen.
