A **dedicated phone** is reserved for your organization for its rental period.
It keeps its apps and device state between sessions.

- Rent by day, week, or month.
- Reuse the same `phone_id`.
- Sessions on the phone add no phone-time charge.
- Vision and other metered services remain separate usage.

## Rent or manage a phone

Rentals are dashboard actions:

1. Open [**Phones**](https://app.axilio.ai/dashboard/axilio/phones).
2. Click **Rent A Phone**.
3. Choose a rental period and complete checkout.
4. Open [**Billing**](https://app.axilio.ai/dashboard/axilio/billing), then
   choose **Dedicated Phones** to inspect or cancel a renewal.

The public API, SDKs, and CLI do not start checkout, renew, or cancel a rental.

## Read rental subscriptions

<Tabs sync={false}>
  <Tab title="Python SDK">
    ```python
    rentals = client.billing.get_rental_subscriptions()

    for rental in rentals.subscriptions or []:
        print(rental.phone_id, rental.status, rental.current_period_end)
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    rentals, err := api.Billing.GetRentalSubscriptions(ctx)
    if err != nil {
        log.Fatal(err)
    }
    for _, rental := range rentals.Subscriptions {
        phoneID := "not assigned"
        if rental.PhoneID != nil {
            phoneID = *rental.PhoneID
        }
        fmt.Println(phoneID, rental.Status, rental.CurrentPeriodEnd)
    }
    ```
  </Tab>

  <Tab title="REST API">
    REST API References:

    - [**List phone rentals**](/api-reference/rest/billing/list-phone-rentals): `GET /billing/phone-rental-subscriptions`

    ```bash
    curl --silent --show-error --fail-with-body \
      --url https://api.axilio.ai/api/v1/billing/phone-rental-subscriptions \
      --header "X-Axilio-Api-Key: $AXILIO_API_KEY"
    ```
  </Tab>
</Tabs>

## Use your phone

Find the ID with `axilio phones mine` or
`client.phones.list(ownership="dedicated")`, then pin it:

```bash
axilio sessions start --phone-id ph_123
```

The dashboard also lets you choose any idle dedicated phone or one exact phone.
