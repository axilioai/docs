A **dedicated device** is a specific phone you rent. It is reserved for your
organization around the clock for the rental period.

- It's the **same phone every time**, so apps stay logged in and set up the way
  you left them.
- You pay a **flat rental** (daily, weekly, or monthly). Sessions on a dedicated
  phone cost **\$0** in device time.

## Rent one

Dedicated phones are billed as a flat rental:

<div id="axilio-rental-plans" />

Rentals start in the dashboard:

<Tabs sync={false}>
  <Tab title="Dashboard">
    1. Open [**Phones**](https://app.axilio.ai/dashboard).
    2. Click **Rent A Phone**.
    3. Choose **Daily**, **Weekly**, or **Monthly**.
    4. Complete checkout. The phone appears on **Phones** after the rental is ready.
  </Tab>

  <Tab title="CLI">
    The CLI does not currently create phone rentals. Use **Phones → Rent A Phone**
    in the dashboard.
  </Tab>

  <Tab title="Python SDK">
    The current Python SDK can inspect rental subscriptions but does not start a
    rental checkout. Use the dashboard to rent a phone.
  </Tab>

  <Tab title="Go SDK">
    The current Go SDK can inspect rental subscriptions but does not start a
    rental checkout. Use the dashboard to rent a phone.
  </Tab>
</Tabs>

## Use your dedicated phone

Select a dedicated phone by its `phone_id` when you start a session:

<Tabs sync={false}>
  <Tab title="Dashboard">
    1. Open **Sessions** and click **Allocate A Phone**.
    2. Choose **Use A Dedicated Phone**.
    3. Select the phone and click **Allocate**.
  </Tab>

  <Tab title="CLI">
    ```bash
    axilio phones mine
    eval "$(axilio sessions start --phone-id ph_123 --export)"
    axilio phone observe
    axilio sessions stop "$AXILIO_SESSION" --yes
    ```
  </Tab>

  <Tab title="Python SDK">
    ```python
    dedicated = client.phones.list(ownership="dedicated")
    phone = dedicated.phones[0]

    with client.session("android", phone_id=phone.phone_id) as driver:
        driver.observe()
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    dedicated, err := api.Phones.List(ctx, &platformgo.PhonesListRequest{
        Ownership: platformgo.PhonesListRequestOwnershipDedicated,
    })
    if err != nil {
        log.Fatal(err)
    }
    if len(dedicated.Phones) == 0 {
        log.Fatal("no dedicated phones found")
    }

    allocation, err := api.Phones.Allocate(ctx, &platformgo.PhoneAllocateRequest{
        PhoneType: platformgo.PhoneAllocateRequestPhoneTypeAndroid,
        PhoneID:   platformgo.String(dedicated.Phones[0].PhoneID),
    })
    if err != nil {
        log.Fatal(err)
    }
    defer api.Phones.Deallocate(ctx, &platformgo.PhonesDeallocateRequest{
        PhoneID: allocation.PhoneID,
    })
    ```
  </Tab>
</Tabs>

## Manage your rentals

<Tabs sync={false}>
  <Tab title="Dashboard">
    1. Open **Settings → Billing**.
    2. Select **Dedicated Phones** to see each rental and its renewal date.
    3. Click **Cancel** on a rental to stop renewal at the end of its current period.

    You can also open **Phones** and click **Subscription** on a phone to manage
    its subscription.
  </Tab>

  <Tab title="CLI">
    The CLI does not currently list or change rental subscriptions. Use the
    dashboard.
  </Tab>

  <Tab title="Python SDK">
    The SDK can list rentals. Cancellation and checkout remain dashboard actions.

    ```python
    rentals = client.billing.get_rental_subscriptions()

    for rental in rentals.subscriptions or []:
        print(rental.phone_id, rental.status, rental.current_period_end)
    ```
  </Tab>

  <Tab title="Go SDK">
    The SDK can list rentals. Cancellation and checkout remain dashboard actions.

    ```go
    rentals, err := api.Billing.GetRentalSubscriptions(ctx)
    if err != nil {
        log.Fatal(err)
    }

    for _, rental := range rentals.Subscriptions {
        fmt.Println(rental.PhoneID, rental.Status, rental.CurrentPeriodEnd)
    }
    ```
  </Tab>
</Tabs>
