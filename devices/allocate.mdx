The easy way to control a dedicated phone is a **session**. It gives you a
driver and releases the phone when you're done:

<Tabs sync={false}>
  <Tab title="Dashboard">
    1. Open [**Sessions**](https://app.axilio.ai/dashboard).
    2. Click **Allocate A Phone** and choose **Use A Dedicated Phone**.
    3. Select a phone, optionally enter a session name or idle timeout, then
       click **Allocate**.
    4. Use the live view to tap the **Settings** icon.
    5. Click **Deallocate** when you finish.
  </Tab>

  <Tab title="CLI">
    ```bash
    axilio phones mine
    eval "$(axilio sessions start --phone-id ph_123 --export)"
    axilio phone tap --query "the Settings icon"
    axilio sessions stop "$AXILIO_SESSION" --yes
    ```
  </Tab>

  <Tab title="Python SDK">
    ```python
    from axilio.platform import Client

    client = Client()

    phones = client.phones.list(ownership="dedicated")
    phone = phones.phones[0]

    with client.session("android", phone_id=phone.phone_id) as driver:
        driver.find(query="the Settings icon").tap()
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    allocation, err := api.Phones.Allocate(ctx, &platformgo.PhoneAllocateRequest{
        PhoneType: platformgo.PhoneAllocateRequestPhoneTypeAndroid,
        Pool:      platformgo.PhoneAllocateRequestPoolDedicated.Ptr(),
    })
    if err != nil {
        log.Fatal(err)
    }
    defer api.Phones.Deallocate(ctx, &platformgo.PhonesDeallocateRequest{
        PhoneID: allocation.PhoneID,
    })

    if allocation.ControlURL == nil {
        log.Fatal("allocation returned no control URL")
    }
    driver := mobile.ConnectRemote(*allocation.ControlURL)
    defer driver.Close()

    settings, err := driver.Find("the Settings icon")
    if err != nil {
        log.Fatal(err)
    }
    if err := settings.Tap(); err != nil {
        log.Fatal(err)
    }
    ```
  </Tab>
</Tabs>

## Pick a specific phone

You can allocate any available dedicated phone or select an exact phone by
`phone_id`:

<Tabs sync={false}>
  <Tab title="Dashboard">
    1. Open [**Sessions**](https://app.axilio.ai/dashboard).
    2. Click **Allocate A Phone**, then choose **Use A Dedicated Phone**.
    3. Select the phone, optionally enter a name or idle timeout, and click **Allocate**.
  </Tab>

  <Tab title="CLI">
    ```bash
    axilio phones mine
    eval "$(axilio sessions start --phone-id ph_123 --export)"
    axilio phone observe
    axilio sessions stop "$AXILIO_SESSION" --yes
    ```
  </Tab>

  <Tab title="Python SDK">
    ```python
    dedicated = client.phones.list(ownership="dedicated")
    phone = dedicated.phones[0]

    with client.session("android", phone_id=phone.phone_id) as driver:
        driver.observe()
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    dedicated, err := api.Phones.List(ctx, &platformgo.PhonesListRequest{
        Ownership: platformgo.PhonesListRequestOwnershipDedicated,
    })
    if err != nil {
        log.Fatal(err)
    }
    if len(dedicated.Phones) == 0 {
        log.Fatal("no dedicated phones found")
    }

    allocation, err := api.Phones.Allocate(ctx, &platformgo.PhoneAllocateRequest{
        PhoneType: platformgo.PhoneAllocateRequestPhoneTypeAndroid,
        PhoneID:   platformgo.String(dedicated.Phones[0].PhoneID),
    })
    if err != nil {
        log.Fatal(err)
    }
    defer api.Phones.Deallocate(ctx, &platformgo.PhonesDeallocateRequest{
        PhoneID: allocation.PhoneID,
    })
    ```
  </Tab>
</Tabs>

## Get and release it yourself

If you need to control the allocation lifetime yourself, allocate and release it
explicitly:

<Tabs sync={false}>
  <Tab title="Dashboard">
    1. Open **Sessions** and click **Allocate A Phone**.
    2. Choose **Use A Dedicated Phone**, select a phone, and click **Allocate**.
    3. Keep the session open for as long as you need it.
    4. Click **Deallocate** in the session when you finish.
  </Tab>

  <Tab title="CLI">
    ```bash
    axilio phones mine
    eval "$(axilio sessions start --phone-id ph_123 --export)"
    axilio sessions current
    axilio sessions stop "$AXILIO_SESSION" --yes
    ```
  </Tab>

  <Tab title="Python SDK">
    ```python
    device = client.phones.allocate(phone_type="android", pool="dedicated")
    print(device.phone_id, device.session_id)

    # ... use the phone ...

    client.phones.deallocate(device.phone_id)
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    device, err := api.Phones.Allocate(ctx, &platformgo.PhoneAllocateRequest{
        PhoneType: platformgo.PhoneAllocateRequestPhoneTypeAndroid,
        Pool:      platformgo.PhoneAllocateRequestPoolDedicated.Ptr(),
    })
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(device.PhoneID, device.SessionID)

    // ... use the phone ...

    _, err = api.Phones.Deallocate(ctx, &platformgo.PhonesDeallocateRequest{
        PhoneID: device.PhoneID,
    })
    if err != nil {
        log.Fatal(err)
    }
    ```
  </Tab>
</Tabs>

<Warning>
  If you allocate a phone directly, call `deallocate` when you finish so it is
  available for another session. Dedicated-phone sessions do not add device-time
  charges; the phone is covered by its flat rental. `session()` deallocates
  automatically when its block exits. Axilio also ends sessions automatically at
  their timeout or one-hour maximum duration.
</Warning>

## What you get back

Besides `phone_id` and `session_id`, an allocation returns three ready-to-use
connection URLs. Each is scoped to this one session and stops working when the
session ends:

| Field | What it's for |
| --- | --- |
| `control_url` | Drive the phone programmatically. The SDK uses this for you. |
| `telemetry_url` | A WebSocket streaming the session's [events live](/observability/telemetry). |
| `live_view_url` | A hosted page with the phone's live, interactive screen — [embeddable in your app](/observability/embed-live-view). Treat it as a secret. |
