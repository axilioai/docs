Use the dedicated-phone inventory to choose the `phone_id` for a session. A
phone can be allocated when its `status` is `active` and
`current_session_id` is empty. The full inventory also shows phones already in
a session and phones whose status is `inactive`, `maintenance`, or `suspended`.

## Find a phone

<Tabs sync={false}>
  <Tab title="Dashboard">
    Open [**Phones**](https://app.axilio.ai/dashboard). Search or filter your
    dedicated inventory, then choose **Allocate** on an idle phone.
  </Tab>

  <Tab title="CLI">
    ```bash
    # Dedicated phones that can be allocated now.
    axilio phones list

    # Complete dedicated inventory, including busy and offline phones.
    axilio phones mine
    axilio phones mine -o json
    ```
  </Tab>

  <Tab title="Python SDK">
    ```python
    inventory = client.phones.list(ownership="dedicated")

    for phone in inventory.phones or []:
        print(
            phone.phone_id,
            phone.nickname,
            phone.status,
            phone.current_session_id,
        )
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    inventory, err := api.Phones.List(ctx, &platformgo.PhonesListRequest{
        Ownership: platformgo.PhonesListRequestOwnershipDedicated,
    })
    if err != nil {
        log.Fatal(err)
    }
    for _, phone := range inventory.Phones {
        fmt.Println(phone.PhoneID, phone.Status, phone.CurrentSessionID)
    }
    ```
  </Tab>

  <Tab title="REST API">
    ```bash
    curl --silent --show-error --fail-with-body \
      --url "https://api.axilio.ai/api/v1/phones?ownership=dedicated" \
      --header "X-Axilio-Api-Key: $AXILIO_API_KEY"
    ```

    This endpoint returns the full rented inventory. Require `status=active`
    and an empty `current_session_id`, then handle an allocation
    conflict in case another session claims it first.

    [REST reference: List the organization's phones](/api-reference/rest/phones/list-the-orgs-phones)
  </Tab>
</Tabs>

Pass a returned `phone_id` to [Allocate a phone](/devices/allocate) when you
start the session.
