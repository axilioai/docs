## Your dedicated phones

List every [dedicated phone](/devices/dedicated) your organization rents,
including phones that are busy or offline:

<Tabs sync={false}>
  <Tab title="Dashboard">
    1. Open [**Phones**](https://app.axilio.ai/dashboard).
    2. Search by phone name or use the **Status**, **Type**, and rental-expiration filters.
    3. Open a phone to inspect its status, model, location, and subscription.
  </Tab>

  <Tab title="CLI">
    ```bash
    axilio phones mine
    ```

    Add `-o json` for structured output.
  </Tab>

  <Tab title="Python SDK">
    ```python
    dedicated = client.phones.list(ownership="dedicated")

    for phone in dedicated.phones:
        print(phone.phone_id, phone.nickname, phone.status)
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    dedicated, err := api.Phones.List(ctx, &platformgo.PhonesListRequest{
        Ownership: platformgo.PhonesListRequestOwnershipDedicated,
    })
    if err != nil {
        log.Fatal(err)
    }

    for _, phone := range dedicated.Phones {
        fmt.Println(phone.PhoneID, phone.Nickname, phone.Status)
    }
    ```
  </Tab>
</Tabs>

Pass a phone's `phone_id` to [`session`](/devices/allocate) to use that exact
phone. A phone with an active status and no current session is available to use.
