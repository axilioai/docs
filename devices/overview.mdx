A device is a carrier-connected Android phone that agents can operate
programmatically. A session is temporary access to one of these devices (phones).

<Tabs sync={false}>
  <Tab title="Dashboard">
    1. Open [**Sessions**](https://app.axilio.ai/dashboard).
    2. Click **Allocate A Phone**.
    3. Choose **Use A Dedicated Phone** and select one of your phones.
    4. Optionally enter a name or idle timeout, then click **Allocate**. The
       session opens with a live, interactive view of the phone.
    5. Click **Deallocate** when you finish to release the phone.
  </Tab>

  <Tab title="CLI">
    The current CLI release still targets the pre-`0.72` session endpoints. Use
    the dashboard, an SDK, or REST to allocate and release a phone until the CLI
    is updated.
  </Tab>

  <Tab title="Python SDK">
    The context manager releases the phone when the block exits:

    ```python
    from axilio.platform import Client

    client = Client()

    with client.session("android", phone_id="ph_123") as driver:
        driver.observe()
    ```
  </Tab>

  <Tab title="Go SDK">
    Allocate a phone and always release it when the function returns:

    ```go
    ctx := context.Background()
    api := client.NewClient(
        option.WithBaseURL("https://api.axilio.ai/api/v1"),
        option.WithAPIKey(os.Getenv("AXILIO_API_KEY")),
    )

    allocation, err := api.Phones.Allocate(ctx, &platformgo.PhoneAllocateRequest{
        PhoneType: platformgo.PhoneAllocateRequestPhoneTypeAndroid,
        Pool:      platformgo.PhoneAllocateRequestPoolDedicated.Ptr(),
    })
    if err != nil {
        log.Fatal(err)
    }
    defer api.Phones.Deallocate(ctx, &platformgo.PhonesDeallocateRequest{
        PhoneID: allocation.PhoneID,
    })

    fmt.Println(allocation.PhoneID, allocation.SessionID)
    ```
  </Tab>

  <Tab title="REST API">
    ```bash
    ALLOCATION=$(curl --silent --show-error --fail-with-body --request POST \
      --url https://api.axilio.ai/api/v1/phones:allocate \
      --header "X-Axilio-Api-Key: $AXILIO_API_KEY" \
      --header "Content-Type: application/json" \
      --data '{
        "phone_type": "android",
        "pool": "dedicated"
      }')
    PHONE_ID=$(printf '%s' "$ALLOCATION" | jq -r '.phone_id')
    printf '%s\n' "$ALLOCATION" | jq

    curl --request POST \
      --url "https://api.axilio.ai/api/v1/phones/$PHONE_ID:deallocate" \
      --header "X-Axilio-Api-Key: $AXILIO_API_KEY"
    ```

    REST manages the session lifecycle. Phone commands use the
    `control_url` WebSocket returned by allocation.
  </Tab>
</Tabs>

## How it fits with the driver

The Platform gives you access to the phone. The [driver](/driver/overview)
controls it. `session()` opens your selected dedicated phone and hands you a
driver to operate it.
