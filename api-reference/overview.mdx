The REST reference is generated from Axilio's public OpenAPI contract. It covers
the customer-facing operations available through `api.axilio.ai`. Each endpoint
shows its parameters, request and response schemas, and a **Try it** panel.

Use the [Python SDK](/quickstart#python), [Go SDK](/quickstart#go), or [CLI](/cli) when you want a typed or
interactive interface. Use the REST API from another runtime or when you need
direct control over HTTP requests.

## Base URLs

| API | Base URL |
|---|---|
| REST API | `https://api.axilio.ai/api/v1` |
| Vision API ([Argus](/drivers/models)) | `https://argus.axilio.ai` |

## Authentication

Send your API key in the `X-Axilio-Api-Key` header:

```bash
curl https://api.axilio.ai/api/v1/phones/availability \
  -H "X-Axilio-Api-Key: axl_your_key_here"
```

Get a key from [**API Keys**](https://app.axilio.ai/dashboard/axilio/api-keys). See
[Authentication](/authentication) for the SDK equivalent.

</Note>

## Roles & permissions

Everyone in an organization has one of three roles. The roles are hierarchical,
so each role includes the permissions of the roles below it:

| Role | Can do |
|---|---|
| **Viewer** | Read organization, phone, session, workflow, run, file, Telemetry, usage, and billing resources. |
| **Member** | Everything a viewer can do, plus allocate and manage phones, start or cancel runs, edit workflows, and manage or deliver files. |
| **Admin** | Everything a member can do, plus manage API keys, view pending invitations, and update auto-recharge or usage-alert settings. |

Authenticated operations declare an `x-required-role` value in the OpenAPI
contract. This value is the minimum role, not an exclusive role. `viewer` allows
viewers, members, and admins. `member` allows members and admins. `admin` allows
admins only.

Not sure what you are? Check your role in
[**Settings → Members**](https://app.axilio.ai/dashboard/axilio/settings/members).
