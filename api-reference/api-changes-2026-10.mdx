API 0.126.0 makes the REST API follow one set of naming rules everywhere. Some
parameters, response fields, paths and webhook fields have new names. The old
names stop working in this release, so update your code and upgrade your
clients. The same release puts every metrics endpoint on one contract (see
[Metrics](#metrics)).

## Upgrade your clients

The SDK and CLI releases that follow API 0.126.0 use the new names. Earlier
releases call the old ones and fail.

```bash
pip install -U axilio
go get github.com/axilioai/platform-go@latest
brew upgrade axilio
```

## The rules

| Concept | Rule |
| --- | --- |
| Sort | One `order_by=<field> [asc\|desc]`, for example `order_by=created_at desc` (URL-encoded as `created_at%20desc`). The direction defaults to `desc`. |
| Filters | Named after the field they match: `status`, never `status_filter`. Most filters repeat to match several values. |
| Search | Free text is `search`. |
| Time windows | `<field>_after` and `<field>_before`, over the field they filter, for example `allocated_after`. |
| Metrics | Every `GET /{area}/metrics` takes the same window and returns `{"points": [...]}`. See [Metrics](#metrics). |
| Timestamps | Every timestamp field ends in `_at`. |
| Money | Every amount is in microdollars: 1,000,000 = $1.00, so cents × 10,000. Fields end in `_microdollars`. |
| Updates | `PATCH`, with only the fields you are changing. |
| Actions | A `:verb` on the resource, for example `POST /files/{file_id}:complete`. |
| Paths | A `POST` creates in a collection or runs a `:verb`. A subset of a list is a filter, never a path segment. |
| Spelling | Runs and sessions say `cancelled` (`cancelled_at`). Billing keeps Stripe's `canceled`. |

| `GET /phones/sessions` | `sort`, `order`, `started_after`, `started_before`, `ended_after`, `ended_before` | `order_by`, `allocated_after`, `allocated_before`, `deallocated_after`, `deallocated_before` |

`GET /api-keys` also takes `search`, `created_by_id`, `created_after`, `created_before` and `order_by`. `GET /workflows` also takes `order_by`, whose field is a path into the listed item, for example `order_by=workflow.name asc`. Both are additions, so existing calls keep working.

## Metrics

`GET /usage/metrics` and `GET /webhooks/metrics` follow one contract, and
every metrics endpoint added later will too.

| Parameter | Rule |
| --- | --- |
| `period_start_at`, `period_end_at` | Both optional. The end defaults to now, and the start to 7 days before the end. The start may be at most a year before now. The window holds its start and not its end. |
| `granularity` | `hour` or `day`, default `day`. `hour` is allowed for windows of 7 days or less; a longer one is a 422. |
| `time_zone` | An IANA name such as `America/Los_Angeles`, default `UTC`. A day starts at local midnight and an hour on the local hour. An unknown name is a 422. |
| `group_by` | Optional, one dimension from the endpoint's list: `product` on usage, `endpoint_id` on webhooks. |

The response is `{"points": [...]}`: one point per bucket (and per group),
oldest first, each with `period_start_at` and every measure. A measure is
named for its unit (`_microdollars`, `_ms`, `_rate` from 0 to 1, or a plain
count) and is zero for a bucket with no activity. A latency is null when no
attempt in the bucket recorded one. A webhooks window that needs more buckets than the gateway returns in one read is a 400; shorten it.

## Webhook payloads

| Events | Before | Now |
| --- | --- | --- |
| `run.*` | `canceled_at` | `cancelled_at` |
| `invoice.paid`, `invoice.payment_failed` | `amount_cents`, `invoice_date` | `amount_microdollars`, `invoiced_at` |
| `subscription.*` | `current_period_start`, `current_period_end` | `current_period_start_at`, `current_period_end_at` |
| `phone.rental.*` | `plan_price_cents`, `current_period_start`, `current_period_end` | `plan_price_microdollars`, `current_period_start_at`, `current_period_end_at` |

A phone rental's `canceled_at` and a subscription's `canceled` status keep
Stripe's spelling.

The SDKs take the new parameter names as arguments (`period_start_at=` in
Python, `PeriodStartAt` in Go). These methods also moved:

| `client.phones.nickname(...)` | `client.phones.update(phone_id, nickname=...)` | `api.Phones.Update` |
