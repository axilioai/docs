Dedicated phones are real Android devices reserved exclusively for your
organization. Pricing is per phone for the rental period you choose.

<div id="axilio-rental-plans" />

Every dedicated-phone rental includes:

- Exclusive access to one phone for your organization.
- Unlimited phone hours during the rental period.
- Persistent apps and device state between sessions.
- No additional phone-time charge for sessions on that phone.

<Note>
  Vision inference and other metered services are billed separately. See
  [Models and pricing](/drivers/models) for current inference pricing.
</Note>

## Rent a phone

Rentals begin in the dashboard:

1. Open [**Phones**](https://app.axilio.ai/dashboard/axilio/phones).
2. Click **Rent A Phone**.
3. Choose **Daily**, **Weekly**, or **Monthly**.
4. Complete checkout to reserve the phone for your organization.

## Inspect or cancel renewals

<Tabs sync={false}>
  <Tab title="Dashboard">
    Open [**Billing**](https://app.axilio.ai/dashboard/axilio/billing), then
    select **Dedicated Phones**. You can inspect the rental period, next
    renewal, payment status, and monthly-equivalent cost. You can also cancel
    an automatic renewal from this view.
  </Tab>

  <Tab title="Python SDK">
    ```python
    rentals = client.billing.get_rental_subscriptions()

    for rental in rentals.subscriptions or []:
        print(
            rental.phone_id,
            rental.plan_name,
            rental.status,
            rental.current_period_end,
        )
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    rentals, err := api.Billing.GetRentalSubscriptions(ctx)
    if err != nil {
        log.Fatal(err)
    }
    for _, rental := range rentals.Subscriptions {
        phoneID := "not assigned"
        if rental.PhoneID != nil {
            phoneID = *rental.PhoneID
        }
        fmt.Println(
            phoneID,
            rental.PlanName,
            rental.Status,
            rental.CurrentPeriodEnd,
        )
    }
    ```
  </Tab>

  <Tab title="REST API">
    REST API References:

    - [**List phone rentals**](/api-reference/rest/billing/list-phone-rentals): `GET /billing/phone-rental-subscriptions`

    ```bash
    curl --silent --show-error --fail-with-body \
      --url https://api.axilio.ai/api/v1/billing/phone-rental-subscriptions \
      --header "X-Axilio-Api-Key: $AXILIO_API_KEY"
    ```
  </Tab>
</Tabs>

The SDKs and REST API can inspect rentals. Starting checkout and canceling a
renewal remain dashboard actions.
