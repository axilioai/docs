A plan sets the included balance, concurrent-run limit, and usage rates for your
organization.

<div id="axilio-plans" />

The dashboard is the authority for the plans currently available to your
organization.

## Read the active plan

<Tabs sync={false}>
  <Tab title="Dashboard">
    Open [**Billing**](https://app.axilio.ai/dashboard) and choose your
    organization. The plan card shows the active plan and renewal period.
  </Tab>

  <Tab title="CLI">
    ```bash
    axilio billing plan
    ```
  </Tab>

  <Tab title="Python SDK">
    ```python
    subscription = client.billing.get_subscription()

    print(subscription.plan_name)
    print(subscription.included_balance_display)
    print(subscription.max_concurrent_runs)
    print(subscription.current_period_end)
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    subscription, err := api.Billing.GetSubscription(ctx)
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(subscription.PlanName, subscription.MaxConcurrentRuns)
    ```
  </Tab>

  <Tab title="REST API">
    Use `GET /api/v1/billing/subscription`.
  </Tab>
</Tabs>

## Change the plan

Plan upgrades, downgrades, and checkout are dashboard-only actions. Open
**Billing**, click the plan-management action, and complete the prompted flow.

The CLI, SDKs, and public REST API do not create checkout or customer-portal
sessions.

## Dedicated-phone rentals

Dedicated phones use separate flat daily, weekly, or monthly subscriptions:

<div id="axilio-rental-plans" />

Start, renew, or cancel a rental in the dashboard. SDKs and REST can read the
organization's subscriptions:

```python
rentals = client.billing.get_rental_subscriptions()
for rental in rentals.subscriptions or []:
    print(rental.phone_id, rental.status, rental.current_period_end)
```

See [Dedicated phones](/devices/dedicated) for allocation behavior.
