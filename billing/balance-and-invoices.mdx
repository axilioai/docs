## Check your balance

<Tabs sync={false}>
  <Tab title="Dashboard">
    1. Open [**Settings → Billing**](https://app.axilio.ai/dashboard).
    2. Read the **Balance** card at the top of the page.
  </Tab>

  <Tab title="CLI">
    The CLI does not currently expose billing commands. Check the balance in the
    dashboard or use an SDK.
  </Tab>

  <Tab title="Python SDK">
    ```python
    balance = client.billing.get_balance()

    print(balance.balance_display)        # e.g. $12.34
    print(balance.balance_microdollars)   # the exact amount
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    balance, err := api.Billing.GetBalance(ctx)
    if err != nil {
        log.Fatal(err)
    }

    fmt.Println(balance.BalanceDisplay)
    fmt.Println(balance.BalanceMicrodollars)
    ```
  </Tab>

  <Tab title="REST API">
    ```bash
    curl --request GET \
      --url https://api.axilio.ai/api/v1/billing/balance \
      --header "X-Axilio-Api-Key: $AXILIO_API_KEY"
    ```

    [API reference: Get account balance](/api-reference/rest/billing/get-account-balance)
  </Tab>
</Tabs>

## Add funds

1. Open **Settings → Billing** in the dashboard.
2. Click **Add Funds**.
3. Choose **\$5**, **\$10**, **\$25**, **\$50**, **\$100**, or **Custom**.
4. Click **Add Funds** and complete checkout.

The CLI, SDKs, and public REST API do not currently start an add-funds checkout.

## Invoices

List invoice history and open an invoice PDF:

<Tabs sync={false}>
  <Tab title="Dashboard">
    1. Open **Settings → Billing**.
    2. Select **Invoices**.
    3. Search or filter the invoice list.
    4. Click **PDF** on an invoice to open its PDF.
  </Tab>

  <Tab title="CLI">
    The CLI does not currently list or download invoices. Use the dashboard or an
    SDK.
  </Tab>

  <Tab title="Python SDK">
    ```python
    history = client.billing.get_history(limit=20, offset=0)

    for invoice in history.items or []:
        print(invoice.invoice_number, invoice.status, invoice.formatted_amount)
        if invoice.invoice_pdf_url:
            print(invoice.invoice_pdf_url)
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    history, err := api.Billing.GetHistory(ctx, &platformgo.BillingGetHistoryRequest{
        Limit:  platformgo.Int64(20),
        Offset: platformgo.Int64(0),
    })
    if err != nil {
        log.Fatal(err)
    }

    for _, invoice := range history.Items {
        fmt.Println(invoice.InvoiceNumber, invoice.Status, invoice.FormattedAmount)
        if invoice.InvoicePdfURL != nil {
            fmt.Println(*invoice.InvoicePdfURL)
        }
    }
    ```
  </Tab>

  <Tab title="REST API">
    ```bash
    curl --request GET \
      --url "https://api.axilio.ai/api/v1/billing/history?limit=20&offset=0" \
      --header "X-Axilio-Api-Key: $AXILIO_API_KEY"
    ```

    [API reference: List billing history](/api-reference/rest/billing/list-billing-history)
  </Tab>
</Tabs>
