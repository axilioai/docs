Billing and usage are related but separate:

- [Usage](/usage/overview) shows phone sessions, aggregate spend, and individual
  inference charges.
- **Balance and invoices** show available credit, purchases, and payment
  records.
- **Plans** set included balance, concurrency, and usage rates.
- **Dedicated rentals** reserve one phone at a flat daily, weekly, or monthly
  price.

## What is billed

| Product | Billing model |
| --- | --- |
| Dedicated phone | Flat rental; its sessions add no phone-time charge |
| Vision inference | Metered per call according to the selected model |

Your subscription can add included credit each billing period. Purchased credit
is tracked separately. The balance endpoint reports both components and the
combined total.

## Where actions are available

| Action | Dashboard | CLI | Python / Go / REST |
| --- | --- | --- | --- |
| Read balance and plan | Yes | Yes | Yes |
| Read usage | Yes | Metrics and inferences | Yes |
| List invoices and download PDFs | Yes | No | Yes |
| Configure auto-recharge and balance alerts | Yes | No | Yes |
| Add funds or add a payment method | Yes | No | No |
| Change plan or manage rental checkout/cancellation | Yes | No | Read-only rental/subscription APIs |
