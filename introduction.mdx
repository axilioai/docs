Axilio is a cloud of **real Android phones** that software can control. Your
agent can see a phone's screen and tap, type, swipe, or capture a screenshot in
the same environment a mobile user experiences.

## Why a real phone?

Many mobile apps do not expose a public API for the task you need. Axilio lets
your agent use the app through its screen on physical hardware and a carrier
network.

<Info>
  Axilio phones are physical Android devices, not emulators. A phone can be in
  only one active session at a time.
</Info>

## The core concepts

| Concept | What it means |
|---|---|
| **Phone** | The physical mobile device your organization can allocate. |
| **Session** | A temporary reservation of one phone. Release the session when the work is done. |
| **Driver** | The control interface inside a session. It observes the screen and performs input actions. |
| **Workflow** | Session-driving code saved in Axilio so it can run again unchanged. |
| **Run** | One execution of a workflow. A run receives its own run ID and, after allocation, a distinct session ID. |
| **File** | An item in your organization's library. It either entered by upload or was captured from a session. |
| **Telemetry** | The customer-facing frames, traces, logs, and summaries that explain an execution. |

## A phone session in Python

`Client` authenticates requests and exposes the platform's resource groups.
`client.session()` allocates a phone, connects a driver, and releases the phone
when the block exits.

```python
from axilio.platform import Client

client = Client()  # reads AXILIO_API_KEY from the environment

with client.session("android") as driver:
    screen = driver.observe()
    print(f"Found {len(screen.texts)} text regions")
    png = driver.screenshot()
```

Use the resource groups on the same client to manage phones, workflows, runs,
files, usage, billing, organizations, and API keys. Use the [CLI](/cli) for the
same operational tasks from a terminal, or use the [REST API](/api-reference/overview)
when you need direct HTTP access.
