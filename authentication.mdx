Protected Axilio operations need an **API key** — a secret that identifies your
account. A small number of read-only endpoints, such as the public vision-model
catalog, do not require one.

## Get a key

Create one in the [dashboard](https://app.axilio.ai/dashboard), under
**Settings → API keys**. Keys start with `axl_`.

<Warning>
  Your key is shown once, when you create it. Save it somewhere safe and never
  commit it to your code.
</Warning>

## Use it

Set the key in your environment so the CLI and examples can read it:

```bash
export AXILIO_API_KEY=axl_your_key_here
```

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio status
    ```

    The CLI reads `AXILIO_API_KEY` automatically. To save a key instead, run
    `axilio login --api-key axl_your_key_here`.
  </Tab>

  <Tab title="Python SDK">
    ```python
    from axilio.platform import Client

    client = Client()
    ```

    `Client()` reads `AXILIO_API_KEY` automatically. You can instead pass
    `api_key="axl_your_key_here"`.
  </Tab>

  <Tab title="Go SDK">
    ```go
    api := client.NewClient(
        option.WithAPIKey(os.Getenv("AXILIO_API_KEY")),
        option.WithBaseURL("https://api.axilio.ai/api/v1"),
    )
    ```

    The Go SDK does not read the variable automatically; pass its value when
    constructing the client.
  </Tab>

  <Tab title="REST API">
    ```bash
    curl --request GET \
      --url "https://api.axilio.ai/api/v1/phones?ownership=dedicated" \
      --header "X-Axilio-Api-Key: $AXILIO_API_KEY"
    ```

    [API reference: List phones](/api-reference/rest/phones/list-the-orgs-phones)

    Send the key in `X-Axilio-Api-Key` on every request.
  </Tab>
</Tabs>

## Client configuration

`Client()` also accepts API and Argus hosts, request timeouts, and retry
settings. See [Configuration](/reference/configuration#sdk-client-options) for
every Python and Go client option.

<Note>
  Each key belongs to one organization. If you're in more than one, make a
  separate key for each.
</Note>
