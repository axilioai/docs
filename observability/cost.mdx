Cost is available in two places with different scopes:

- A session's [Telemetry frames](/observability/frames) join billed cost to
  SDK-call and inference spans.
- [Usage](/usage/overview) reports session and inference totals across a time
  range.

Telemetry cost maps and usage row fields whose names end in `_microdollars`
use millionths of a dollar. Divide those values by 1,000,000 to display
dollars. Aggregate Usage `cost_by_product` values are already in dollars.

## Cost in a Telemetry trace

```python
telemetry = client.telemetry(session_id)
trace = telemetry.trace()

for item in trace.spans:
    if item.billed_cost_microdollars is not None:
        print(item.frame.name, item.billed_cost_microdollars)
```

The frame archive returns `sdk_call_costs` and `inference_costs` as
response-level maps. Billed cost is not written into the frame itself. The SDK
helpers perform this join for you.

## Account-wide usage

Use [Usage](/usage/overview) for per-session totals, individual inference
charges, charts, and CLI/API examples. Billing pages cover the account balance,
plan, invoices, and payment settings rather than duplicating usage data.
