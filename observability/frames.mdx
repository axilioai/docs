Frames are the canonical record of what happened during a phone session. The
archive contains completed spans and point-in-time logs ordered by span start
or log time. It works for workflow runs and interactive sessions because every
lookup uses `session_id`.

## Read the retained trace

<Tabs sync={false}>
  <Tab title="Dashboard">
    1. Open [**Sessions**](https://app.axilio.ai/dashboard/axilio/sessions).
    2. Select a completed session, or select an active session and click
       **Observability**.
    3. Inspect completed operations in **Timeline** and output or error logs in
       **Console**.
    4. Select a timeline bar to view its status, duration, attributes, and
       billed cost when available.

    The Dashboard joins the archive's response-level cost maps to their spans.
    For a completed session with a recording, the timeline and console also
    follow the video playhead.
  </Tab>

  <Tab title="CLI">
    ```bash
    axilio sessions trace sess_123
    ```

    The table shows time, frame kind, name, duration, outcome, and billed cost
    when available. Use JSON output for the complete, all-pages response:

    ```bash
    axilio sessions trace sess_123 -o json
    ```

    Add `--follow` to print the archive and then attach to
    [Live Telemetry](/observability/telemetry).
  </Tab>

  <Tab title="Python SDK">
    The high-level helper pages through the archive and joins billed costs:

    ```python
    from axilio.platform import Client

    client = Client()
    telemetry = client.telemetry("sess_123")
    trace = telemetry.trace()

    if trace.retention_expired:
        print("The trace is outside the retention window")

    for item in trace.spans:
        print(
            item.frame.span_type,
            item.frame.name,
            item.duration_ms,
            item.billed_cost_microdollars,
        )

    for log in trace.logs:
        print(log.severity, log.body)
    ```

    Use `telemetry.summary()` for total time, SDK-call time, unobserved time,
    call counts, and billed SDK-call cost. Use `telemetry.logs()` when you only
    need archived logs.

    The generated paginated operation is
    `client.raw.runs.sessions_list_frames(...)`.
  </Tab>

  <Tab title="Go SDK">
    ```go
    package main

    import (
        "context"
        "fmt"
        "log"
        "os"

        "github.com/axilioai/platform-go/client"
        "github.com/axilioai/platform-go/drivers/telemetry"
        "github.com/axilioai/platform-go/option"
    )

    func main() {
        ctx := context.Background()
        api := client.NewClient(option.WithAPIKey(os.Getenv("AXILIO_API_KEY")))
        view := telemetry.NewSession(api, "sess_123")

        trace, err := view.Trace(ctx)
        if err != nil {
            log.Fatal(err)
        }
        if trace.RetentionExpired {
            fmt.Println("The trace is outside the retention window")
        }

        for _, item := range trace.Spans {
            fmt.Println(
                item.Span.SpanType,
                item.Span.Name,
                item.Duration(),
                item.BilledMicrodollars,
            )
        }
        for _, entry := range trace.Logs {
            fmt.Println(entry.Severity, entry.Body)
        }
    }
    ```

    Import the helper from
    `github.com/axilioai/platform-go/drivers/telemetry`. The generated
    paginated operation is `api.Runs.SessionsListFrames(...)`.
  </Tab>

  <Tab title="REST API">
    REST API References:

    - [**List a session's Telemetry frames**](/api-reference/rest/runs/list-a-sessions-telemetry-frames): `GET /phones/sessions/{session_id}/frames`

    Request one page at a time:

    ```bash
    curl --silent --show-error --fail-with-body \
      --request GET \
      --url 'https://api.axilio.ai/api/v1/phones/sessions/sess_123/frames?limit=1000&offset=0' \
      --header "X-Axilio-Api-Key: $AXILIO_API_KEY" \
      | jq
    ```

    Continue with `offset += frames.length` until the offset reaches `total`
    or a page contains no frames. The maximum page size is 1,000.
  </Tab>
</Tabs>

## Interpret a page

| Field | Meaning |
| --- | --- |
| `frames` | This page of span and log frames. |
| `total`, `limit`, `offset` | Pagination state. |
| `sdk_call_costs` | Billed microdollars keyed by SDK-call `span_id`. |
| `inference_costs` | Billed microdollars keyed by inference ID. |
| `retention_expired` | `true` when the trace is outside the organization's retention window and frames are withheld. |

Cost maps belong to the response, not to individual frames. Join an SDK-call
span through its `span_id`. Inference spans carry their inference ID in their
attributes.

## Frame envelope

A completed span looks like this:

```json
{
  "kind": "span",
  "trace_id": "<trace-id>",
  "span_id": "<span-id>",
  "parent_span_id": "<parent-span-id>",
  "span_type": "sdk_call",
  "name": "Screen.observe",
  "phase": "end",
  "start_time_unix_nano": 0,
  "end_time_unix_nano": 0,
  "status": { "code": "ok", "message": "" },
  "attributes": {}
}
```

A log looks like this:

```json
{
  "kind": "log",
  "trace_id": "<trace-id>",
  "span_id": "<span-id>",
  "log_type": "output_log",
  "severity": "INFO",
  "body": "hello",
  "time_unix_nano": 0,
  "attributes": {}
}
```

Common span roles include `session`, `run`, `sdk_call`, `inference`,
`file_push`, and `media_capture`. Common log roles include `output_log`,
`output_error`, `kernel_status`, and `transfer_progress`. These
vocabularies are additive: render an unfamiliar value generically.

An older retained trace can use `phone_session` for its session-root span.
Treat it as `session`.

The live stream emits a span's `start` and `end` phases. The archive
collapses each span into one completed `end` frame. Logs have the same shape
in both places.

## Build tolerant readers

Telemetry evolves without requiring you to update every integration at once.
Build readers that:

- accept unknown fields on a known frame;
- preserve or render unknown `kind`, `span_type`, and `log_type` values;
- accept one frame object or an array from the live stream; and
- avoid treating a new value as a broken trace.

The Python and Go helpers expose unknown frame kinds instead of silently
dropping them.
