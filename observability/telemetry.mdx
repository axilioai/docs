When you allocate a phone, the response includes a `telemetry_url`: a
WebSocket that streams the session's events live — driver calls, vision
inference, and output logs, as structured JSON, the moment they happen.

It's how you watch a session from your own code, pipeline, or UI without
opening the dashboard:

```python
import asyncio
import json

import websockets

device = client.phones.allocate(phone_type="android", pool="dedicated")

async def watch():
    async with websockets.connect(device.telemetry_url) as ws:
        async for frame in ws:
            print(json.loads(frame))

asyncio.run(watch())
```

A few things to know:

- **The URL is self-contained.** Its credential is embedded; connect with any
  WebSocket client, no headers needed.
- **Read-only.** Anything you send on the socket is ignored.
- **Late joiners catch up.** Connecting mid-session replays the recent event
  window, then follows live.
- **It ends with the session.** The URL stops working at deallocation. For
  events after a session ends, use the [events API](/observability/events).
