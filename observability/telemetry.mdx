Telemetry is the structured execution record for a phone session. Its frames
include completed and in-flight operations, inference work, file activity, and
output logs. The live stream and the retained [frame archive](/observability/frames)
use the same envelope.

When Telemetry is enabled, allocating a phone returns a read-only
`telemetry_url` for that session.

## Follow with the CLI

Follow an active session after printing its archived prefix:

```bash
axilio sessions trace <session-id> --follow
```

Follow a run from queueing through its final outcome:

```bash
axilio runs watch <run-id>
```

Both commands reconnect through the frame archive if the live connection is
unavailable. With `-o json`, they emit newline-delimited JSON: one frame per
line followed by a final summary object.

## Follow with Python

The Python helper reconnects automatically, resumes from its last cursor, and
deduplicates replayed frames:

```python
from axilio.platform import Client

client = Client()
allocation = client.phones.allocate(phone_type="android", phone_id="ph_123")

telemetry = client.telemetry(
    allocation.session_id,
    allocation.telemetry_url,
)

for frame in telemetry.tail():
    print(frame)
```

The loop ends after it yields the session's terminal frame. Use
`telemetry.logs(live=True)` when you only need log frames.

## Follow with Go

The Go helper reconnects and resumes from its latest cursor:

```go
view := telemetry.NewSession(
    api,
    allocation.SessionID,
    telemetry.WithTelemetryURL(*allocation.TelemetryURL),
)

stream, err := view.Tail(ctx)
if err != nil {
    return err
}
defer stream.Close()

for {
    frame, err := stream.Next(ctx)
    if errors.Is(err, io.EOF) {
        break
    }
    if err != nil {
        return err
    }
    fmt.Printf("%+v\n", frame)
}

if stream.Gapped() {
    fmt.Println("The live replay window expired; refetch the archived trace")
}
```

Import the helper as
`github.com/axilioai/platform-go/drivers/telemetry`. Check that
`allocation.TelemetryURL` is non-nil before dereferencing it. Delivery is at
least once, so deduplicate replayed frames if your Go consumer requires
exactly-once presentation. When `stream.Gapped()` is true, call `view.Trace`
to rebuild the authoritative trace from the archive.

## Attach to an existing active session

An orchestrated run does not return its allocation response to your process.
Mint a fresh URL for an active session, then attach the same helper:

```python
grant = client.phones.session_telemetry_token(session_id)
telemetry = client.telemetry(session_id, grant.telemetry_url)

for frame in telemetry.tail():
    print(frame)
```

The token operation is org-scoped and read-only. It refuses inactive sessions.
For an ended session, read [archived frames](/observability/frames) instead.

[REST reference: Mint a Telemetry stream URL](/api-reference/rest/phones/mint-a-telemetry-stream-url)

## Stream behavior

- **Treat the URL as a secret.** Its session-scoped credential is embedded, so
  a WebSocket client connects without additional headers.
- **The stream is read-only.** Messages a viewer sends are ignored.
- **Late joiners receive the recent retained window**, then follow new frames.
- **A message can contain one frame or an array of frames.** Readers must
  support both forms.
- **Unknown frame kinds and fields are additive.** Preserve or render them
  generically instead of failing the stream.
- **The URL dies with the session.** The retained archive remains available
  only for your organization's Telemetry-retention window.

<Note>
  Both helpers reconnect, resume from cursor checkpoints, and handle a clean
  session end. Python also deduplicates replayed frames. A Go consumer should
  tolerate duplicates and check `Gapped()`. If you open the WebSocket
  yourself, implement the [reconnect and resume contract](/api-reference/dcp/reconnect).
</Note>
