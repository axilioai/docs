The mobile driver controls the phone inside a session. Its reliable loop is:

1. Observe the current screen.
2. Find a target by visible text or description.
3. Tap, type, swipe, or press a key.
4. Observe or wait for the expected result.

Start with a [dedicated-phone session](/devices/allocate), then use the
interface that fits your program.

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone observe
    axilio phone tap --query "the search icon"
    axilio phone tap --query "the Search field"
    axilio phone type "axilio"
    axilio phone key enter
    axilio phone observe
    ```
  </Tab>

  <Tab title="Python SDK">
    ```python
    from axilio.platform import Client

    client = Client()

    with client.session("android", phone_id="ph_123") as driver:
        driver.find(query="the search icon").tap()
        driver.wait_for_text("Search").type_into("axilio")
        driver.key_press("enter")
        screen = driver.observe()
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    searchIcon, err := driver.Find("the search icon")
    if err != nil {
        log.Fatal(err)
    }
    if err := searchIcon.Tap(); err != nil {
        log.Fatal(err)
    }

    field, err := driver.WaitForText("Search", 10*time.Second, false)
    if err != nil {
        log.Fatal(err)
    }
    if err := field.TypeInto("axilio"); err != nil {
        log.Fatal(err)
    }
    if err := driver.KeyPress(mobile.KeyEnter); err != nil {
        log.Fatal(err)
    }
    screen, err := driver.Observe()
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(len(screen.Texts))
    ```
  </Tab>
</Tabs>

<Note>
  Phone control uses the session's Device Control Protocol WebSocket. The CLI
  and SDK drivers expose these actions; they are not REST endpoints.
</Note>

## Semantic targets and coordinates

Use text or a natural-language query for a tappable target whenever possible.
Coordinates are appropriate for gestures that move the whole screen or for a
fixed point you derived from the current observation.

Only tap, long-press, and swipe have raw coordinate forms. Finding, waiting,
typing, key presses, observation, and screenshots use their own typed inputs.

For complete Python signatures and the corresponding Go methods, see the
[Driver reference](/driver/reference).
