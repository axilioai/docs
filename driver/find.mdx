Find an element before you act on it. Use OCR text matching when a visible label
exists and semantic vision when the target is easier to describe.

The examples assume you already selected a
[dedicated-phone session](/devices/allocate).

## Find by visible text

Text matching returns the first OCR element that matches. By default the match
is a case-insensitive substring. Exact matching is case-sensitive.

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone find-text "Continue" -o json
    axilio phone find-text "Continue" --exact -o json
    ```

    A miss succeeds with `null` in JSON output.
  </Tab>

  <Tab title="Python SDK">
    ```python
    result = driver.find_text("Continue")
    if result is not None:
        result.tap()
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    result, err := driver.FindText("Continue", false)
    if err != nil {
        log.Fatal(err)
    }
    if result != nil {
        if err := result.Tap(); err != nil {
            log.Fatal(err)
        }
    }
    ```
  </Tab>
</Tabs>

If the screen may still be loading, [wait for the text](/driver/wait) instead of
acting on a possible empty result.

## Find every text match

Use a substring for a simple list or a regular expression for structured text.
The two criteria are mutually exclusive.

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone find-all-text "Notification" -o json
    axilio phone find-all-text --pattern '\$[0-9]+\.[0-9]{2}' -o json
    ```

    With neither criterion, `find-all-text` returns every OCR text element. Add
    `--ocr-engine premium` for a harder screen.
  </Tab>

  <Tab title="Python SDK">
    ```python
    for item in driver.find_all_text(contains="Notification"):
        print(item.text)

    prices = driver.find_all_text(pattern=r"\$\d+\.\d{2}")
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    items, err := driver.FindAllText("Notification", "")
    if err != nil {
        log.Fatal(err)
    }
    for _, item := range items {
        fmt.Println(item.Text)
    }
    ```
  </Tab>
</Tabs>

## Find by description

Semantic `find` uses a billable [vision model](/drivers/models). It raises an
element-not-found error when no target matches.

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone find "the search icon" -o json
    ```

    A miss returns the CLI not-found exit status (`4`). Use
    `axilio phone tap --query "the search icon"` when you want to find and tap
    in one command.
  </Tab>

  <Tab title="Python SDK">
    ```python
    from axilio.drivers.mobile import ElementNotFoundError

    try:
        driver.find(query="the search icon").tap()
    except ElementNotFoundError:
        print("search icon not found")
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    target, err := driver.Find("the search icon")
    if err != nil {
        if mobile.IsElementNotFound(err) {
            log.Print("search icon not found")
            return
        }
        log.Fatal(err)
    }
    if err := target.Tap(); err != nil {
        log.Fatal(err)
    }
    ```
  </Tab>
</Tabs>

Review individual inference charges in [Usage](/usage/overview). Prefer OCR
matching when a stable visible label exists.

## Choose the OCR engine and model

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone find "the buy button" \
      --ocr-engine premium \
      --model anthropic/claude-haiku-4.5
    ```

    `find`, `find-all-text`, and `observe` accept an OCR-engine override.
    `find-text` and `wait-for` do not.
  </Tab>

  <Tab title="Python SDK">
    ```python
    driver.find_text("Sign in", ocr_engine="premium")
    driver.find(
        query="the buy button",
        model="anthropic/claude-haiku-4.5",
    )
    ```

    Set defaults for one dedicated-phone session:

    ```python
    with client.session(
        "android",
        phone_id="ph_123",
        default_ocr_engine="premium",
        default_model="anthropic/claude-haiku-4.5",
    ) as driver:
        driver.find_text("Sign in")
        driver.find(query="the buy button")
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    driver := mobile.ConnectRemote(
        controlURL,
        mobile.WithDefaultOCREngine("premium"),
        mobile.WithDefaultModel("anthropic/claude-haiku-4.5"),
    )
    defer driver.Close()

    if _, err := driver.Find("the buy button"); err != nil {
        log.Fatal(err)
    }
    ```
  </Tab>
</Tabs>

Text filtering and wait loops are client-side helpers. Semantic find is backed
by DCP `Screen.find`; none of these live phone operations is a REST endpoint.
