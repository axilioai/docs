A swipe moves between two points. Swipe upward to move down a list; swipe
downward to move up.

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone swipe 540 1600 540 400 --duration-ms 300
    ```

    The CLI swipe command is coordinate-only.
  </Tab>

  <Tab title="Python SDK">
    ```python
    driver.swipe(
        {"x": 540, "y": 1600},
        {"x": 540, "y": 400},
        duration_ms=300,
    )
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    err := driver.Swipe(
        mobile.Coords{X: 540, Y: 1600},
        mobile.Coords{X: 540, Y: 400},
        300,
    )
    if err != nil {
        log.Fatal(err)
    }
    ```
  </Tab>
</Tabs>

The CLI and Python defaults are 300 milliseconds. Go requires the duration
argument explicitly.

## Drag one element to another

Read both positions with [`bounding_box()`](/driver/locator#locator-bounding_box),
then swipe between their centers:

<Tabs sync={false}>
  <Tab title="Python SDK">
    ```python
    def center(box):
        return {"x": box["x"] + box["width"] // 2, "y": box["y"] + box["height"] // 2}

    card = driver.get_by_text("Card").bounding_box().bounds
    archive = driver.get_by_text("Archive").bounding_box().bounds
    driver.swipe(center(card), center(archive), duration_ms=300)
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    card, err := driver.GetByText("Card").BoundingBox()
    if err != nil {
        log.Fatal(err)
    }
    archive, err := driver.GetByText("Archive").BoundingBox()
    if err != nil {
        log.Fatal(err)
    }
    if err := driver.Swipe(card.Bounds.Center(), archive.Bounds.Center(), 300); err != nil {
        log.Fatal(err)
    }
    ```
  </Tab>
</Tabs>

`bounding_box()` waits for each target like any locator action. The drag itself
is DCP `Touch.swipe`. Live swipe actions are not REST operations.
