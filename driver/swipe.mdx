[`swipe`](/driver/reference#driver-swipe) moves between two points on the screen. This is also how you scroll:

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone swipe 540 1600 540 400
    ```
  </Tab>

  <Tab title="Python SDK">
    ```python
    driver.swipe(
        {"x": 540, "y": 1600},
        {"x": 540, "y": 400},
    )
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    start := mobile.Coords{X: 540, Y: 1600}
    end := mobile.Coords{X: 540, Y: 400}

    if err := driver.Swipe(start, end, 300); err != nil {
        log.Fatal(err)
    }
    ```
  </Tab>
</Tabs>

<Note>
  Swiping is how you scroll: swipe **up** (end higher than start) to move *down* a
  list, and the other way to move up. Pass `duration_ms` to change how long the
  gesture takes.
</Note>

## Swipe one thing onto another

Swipe from something you [found](/driver/find) to another, for example to drag a
card onto a target:

<Tabs sync={false}>
  <Tab title="CLI">
    The CLI swipe command uses coordinates. Find both centers, then swipe
    between them:

    ```bash
    read -r CARD_X CARD_Y < <(
      axilio phone find-text "Card" -o json |
        jq -r '.center | "\(.x) \(.y)"'
    )
    read -r ARCHIVE_X ARCHIVE_Y < <(
      axilio phone find-text "Archive" -o json |
        jq -r '.center | "\(.x) \(.y)"'
    )
    axilio phone swipe "$CARD_X" "$CARD_Y" "$ARCHIVE_X" "$ARCHIVE_Y"
    ```
  </Tab>

  <Tab title="Python SDK">
    ```python
    driver.find_text("Card").swipe_to(driver.find_text("Archive"))
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    card, err := driver.FindText("Card", false)
    if err != nil {
        log.Fatal(err)
    }
    if card == nil {
        log.Fatal("Card not found")
    }
    archive, err := driver.FindText("Archive", false)
    if err != nil {
        log.Fatal(err)
    }
    if archive == nil {
        log.Fatal("Archive not found")
    }
    if err := card.SwipeTo(*archive, 300); err != nil {
        log.Fatal(err)
    }
    ```
  </Tab>
</Tabs>

Swiping uses the device-control WebSocket and is not a REST operation.
