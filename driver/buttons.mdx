Some steps need a key press instead of a tap. The current named-key set contains
only Enter.

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone tap --query "the Search field"
    axilio phone type "axilio"
    axilio phone key enter
    ```
  </Tab>

  <Tab title="Python SDK">
    ```python
    from axilio.drivers.mobile import Key

    field = driver.wait_for_text("Search")
    field.type_into("axilio")
    driver.key_press(Key.ENTER)
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    field, err := driver.WaitForText("Search", 10*time.Second, false)
    if err != nil {
        log.Fatal(err)
    }
    if err := field.TypeInto("axilio"); err != nil {
        log.Fatal(err)
    }
    if err := driver.KeyPress(mobile.KeyEnter); err != nil {
        log.Fatal(err)
    }
    ```
  </Tab>
</Tabs>

Key presses travel over the session's Device Control Protocol connection. They
are not REST operations. To type characters into a field, use [Type](/driver/type)
instead.
