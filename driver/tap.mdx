Prefer a text or described target when one exists. Use raw coordinates only
when the action belongs to a fixed point on the current screen.

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone tap --query "the Continue button"
    ```

    `--query` finds the target with semantic vision, waits up to 5 seconds for
    it to appear, and taps its center. You can add `--ocr-engine` or `--model`
    overrides.
  </Tab>

  <Tab title="Python SDK">
    ```python
    driver.get_by_text("Continue").tap()
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    if _, err := driver.GetByText("Continue").Tap(); err != nil {
        log.Fatal(err)
    }
    ```
  </Tab>
</Tabs>

The tap waits up to 5 seconds for the target to appear. Pass `timeout=` (Go:
`mobile.WithTimeout`) for a slower screen, up to 60 seconds.

## Tap an exact point

Coordinates start at `(0, 0)` in the screen's top-left corner.

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone tap 540 1180
    ```
  </Tab>

  <Tab title="Python SDK">
    ```python
    driver.tap({"x": 540, "y": 1180})
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    if err := driver.Tap(mobile.Coords{X: 540, Y: 1180}); err != nil {
        log.Fatal(err)
    }
    ```
  </Tab>
</Tabs>

## Press and hold

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone long-press 540 1180 --duration-ms 1500
    ```

    The CLI long-press command is coordinate-only. The CLI and Python default
    to 800 milliseconds; Go requires the duration explicitly.
  </Tab>

  <Tab title="Python SDK">
    ```python
    box = driver.get_by_text("Photo").bounding_box().bounds
    center = {"x": box["x"] + box["width"] // 2, "y": box["y"] + box["height"] // 2}
    driver.long_press(center, duration_ms=1500)
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    photo, err := driver.GetByText("Photo").BoundingBox()
    if err != nil {
        log.Fatal(err)
    }
    if err := driver.LongPress(photo.Bounds.Center(), 1500); err != nil {
        log.Fatal(err)
    }
    ```
  </Tab>
</Tabs>

A locator has no long-press action, so read the target's position with
[`bounding_box()`](/driver/locator#locator-bounding_box) and hold its center.

A locator tap uses DCP `Locator.tap`. Coordinate taps and long-presses use
`Touch.tap` and `Touch.longPress`. None of them is a REST operation.
