Prefer a semantic or text target when one exists. Use raw coordinates only
when the action belongs to a fixed point on the current screen.

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone tap --query "the Continue button"
    ```

    `--query` finds the target with semantic vision and taps its center. You can
    add `--ocr-engine` or `--model` overrides.
  </Tab>

  <Tab title="Python SDK">
    ```python
    driver.wait_for_text("Continue").tap()
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    button, err := driver.WaitForText("Continue", 10*time.Second, false)
    if err != nil {
        log.Fatal(err)
    }
    if err := button.Tap(); err != nil {
        log.Fatal(err)
    }
    ```
  </Tab>
</Tabs>

## Tap an exact point

Coordinates start at `(0, 0)` in the screen's top-left corner.

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone tap 540 1180
    ```
  </Tab>

  <Tab title="Python SDK">
    ```python
    driver.tap({"x": 540, "y": 1180})
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    if err := driver.Tap(mobile.Coords{X: 540, Y: 1180}); err != nil {
        log.Fatal(err)
    }
    ```
  </Tab>
</Tabs>

## Press and hold

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone long-press 540 1180 --duration-ms 1500
    ```

    The CLI long-press command is coordinate-only. The CLI and Python default
    to 800 milliseconds; Go requires the duration explicitly.
  </Tab>

  <Tab title="Python SDK">
    ```python
    photo = driver.find_text("Photo")
    if photo is not None:
        photo.long_press(duration_ms=1500)
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    photo, err := driver.FindText("Photo", false)
    if err != nil {
        log.Fatal(err)
    }
    if photo != nil {
        if err := photo.LongPress(1500); err != nil {
            log.Fatal(err)
        }
    }
    ```
  </Tab>
</Tabs>

Tap and long-press use DCP `Touch.tap` and `Touch.longPress`; they are not REST
operations.
