Python's high-level `Client` authenticates Platform requests and opens phone
sessions.

```python
from axilio.platform import Client

client = Client()
```

The constructor reads `AXILIO_API_KEY`. See
[Configuration](/reference/configuration) for every client option.

## `client.session()`

Use the context manager so the dedicated phone is released on every exit path:

```python
with client.session("android", phone_id="ph_123") as driver:
    driver.wait_for_text("Continue").tap()
```

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `phone_type` | `"android"` | `"android"` | Device kind. Android is the supported customer platform. |
| `phone_id` | `str` | `None` | Dedicated phone to allocate. Pass this for customer-facing sessions. |
| `workflow_id` | `str` | `None` | Associate a direct allocation with a workflow. |
| `open_timeout` | `float` | `10.0` | Seconds to wait while opening the DCP connection. |
| `default_ocr_engine` | `str` | `None` | Session-wide OCR default; omission resolves to `free`. |
| `default_model` | `str` | `None` | Session-wide semantic-vision model; omission lets the service choose. |

The yielded [driver](/driver/reference) closes its connection and deallocates the
phone when the block exits. A per-call OCR engine or model overrides the
session default.

## Call Argus on your own input

The phone driver already uses Argus for screen understanding. Call the Argus
API directly when the input is a screenshot or an accessibility tree that you
provide. Argus has one operation per kind of input, because a screenshot is
answered with a box and a tree is answered with a node. The CLI does not
expose a direct Argus command.

<Note>
  The Python and Go clients for the Argus API are being regenerated for these
  operations. Until that SDK release, call them over HTTP as shown below. Every
  operation except the model list needs your API key in `X-Axilio-Api-Key`.
</Note>

### Locate a described target in a screenshot

REST API References:

- [**Screenshots: locate**](/api-reference/argus/screenshots-locate): `POST /api/v1/screenshots:locate`

```bash
jq -n \
  --arg image "$IMAGE_B64" \
  --arg query "the blue Continue button" \
  '{image: $image, query: $query}' |
  curl --silent --show-error --fail-with-body \
    --request POST \
    --url https://argus.axilio.ai/api/v1/screenshots:locate \
    --header "X-Axilio-Api-Key: $AXILIO_API_KEY" \
    --header "Content-Type: application/json" \
    --data-binary @-
```

When `found` is true, the response carries either a pixel `bbox` or, if you
sent OCR results as `texts`, a `matched_text_index` into that list. The request
also accepts an optional `model`.

### Locate a described node in an accessibility tree

REST API References:

- [**Accessibility trees: locate**](/api-reference/argus/accessibility-trees-locate): `POST /api/v1/accessibility-trees:locate`

```bash
jq -n \
  --arg query "the Sign in button" \
  '{
    query: $query,
    nodes: [
      {node_id: "13", role: "textbox", name: "Password"},
      {node_id: "14", role: "button", name: "Sign in"}
    ]
  }' |
  curl --silent --show-error --fail-with-body \
    --request POST \
    --url https://argus.axilio.ai/api/v1/accessibility-trees:locate \
    --header "X-Axilio-Api-Key: $AXILIO_API_KEY" \
    --header "Content-Type: application/json" \
    --data-binary @-
```

The response names one of your `node_id` values, or reports `found: false`.
Each node can also carry `value`, pixel `bounds`, and a `platform` object of
native attributes, and the request accepts an optional screenshot as `image`.

### Detect text and icons in a screenshot

REST API References:

- [**Screenshots: detect**](/api-reference/argus/screenshots-detect): `POST /api/v1/screenshots:detect`

```bash
jq -n --arg image "$IMAGE_B64" \
  '{image: $image, inference_type: "combined", ocr_engine: "free"}' |
  curl --silent --show-error --fail-with-body \
    --request POST \
    --url https://argus.axilio.ai/api/v1/screenshots:detect \
    --header "X-Axilio-Api-Key: $AXILIO_API_KEY" \
    --header "Content-Type: application/json" \
    --data-binary @-
```

Detection also accepts `confidence_threshold` and `nms_iou_threshold`.

### List supported models

REST API References:

- [**Models: list**](/api-reference/argus/list-models): `GET /api/v1/models`

```bash
curl --silent --show-error --fail-with-body \
  --url https://argus.axilio.ai/api/v1/models
```

The catalog is public, so this request does not need an API key.

Argus errors use the [problem details](/reference/errors#problem-details)
shape, the same as the REST API.
