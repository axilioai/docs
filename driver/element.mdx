Python `driver.find()` and `driver.find_text()` return an `Element`; Go returns
the corresponding `mobile.Element`. An element remembers its location and the
driver that found it, so it can tap, type, long-press, or swipe from its center.

<Tabs sync={false}>
  <Tab title="Python SDK">
    ```python
    element = driver.find_text("Sign in")
    if element is not None:
        print(element.center, element.confidence)
        element.tap()
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    element, err := driver.FindText("Sign in", false)
    if err != nil {
        log.Fatal(err)
    }
    if element != nil {
        fmt.Println(element.Center, element.Confidence)
        if err := element.Tap(); err != nil {
            log.Fatal(err)
        }
    }
    ```
  </Tab>
</Tabs>

The CLI prints the same element data in table or JSON output, but it does not
retain a persistent element object between commands. There is no REST element
resource.

## Methods

### Tap the center {#element-tap}

`element.tap()` and `element.Tap()` tap the element's center.

### Tap, then type {#element-type_into}

`element.type_into(text)` and `element.TypeInto(text)` tap the element, then
type `text`.

### Press and hold {#element-long_press}

`element.long_press(duration_ms=...)` and `element.LongPress(durationMs)` press
and hold the element. Python defaults to 800 ms; Go requires a duration.

### Swipe to another element {#element-swipe_to}

`element.swipe_to(other, duration_ms=...)` and
`element.SwipeTo(other, durationMs)` swipe from one element to another. Python
defaults to 300 ms; Go requires a duration.

Guard an OCR lookup before calling an element method:

```python
card = driver.find_text("Card")
archive = driver.find_text("Archive")
if card is None or archive is None:
    raise RuntimeError("drag target is not visible")
card.swipe_to(archive, duration_ms=300)
```

## Fields

| Python | Go | Description |
| --- | --- | --- |
| `element.center` | `element.Center` | Tap point at the element's center. |
| `element.bbox` | `element.BBox` | Bounding box in screen pixels. |
| `element.text` | `element.Text` | Recognized text, when present. |
| `element.confidence` | `element.Confidence` | Match confidence from `0` to `1`. |
| `element.source` | `element.Source` | `ocr` when the returned result carries recognized text; otherwise `vlm`. |

<Note>
  `find_text` returns `None` or `nil` on a miss. Semantic `find` instead returns
  an `element_not_found` error.
</Note>
