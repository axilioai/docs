An `Element` is what [`driver.find()`](/driver/reference#driver-find) and
[`driver.find_text()`](/driver/reference#driver-find_text) return. Act on it
directly, or read its fields to drive [raw input](/driver/reference#tapping).

This page documents the Python SDK object. See the driver task guides for CLI
and Go SDK examples.

```python
el = driver.find_text("Sign in")
el.tap()
print(el.center, el.confidence)
```

## Methods

### `element.tap()`
Tap the element's center.

**Returns** `None`.

### `element.type_into()`
Tap the element, then type `text` into it.

```python
driver.find_text("Search").type_into("axilio")
```

**Returns** `None`. `text` is a `str`.

### `element.long_press()`
Press and hold the element, for example to open a menu.

```python
driver.find_text("Photo").long_press(duration_ms=1500)
```

**Returns** `None`. `duration_ms` is an `int`, default `800`.

### `element.swipe_to()`
Swipe from this element to another `Element` — for example to drag a card onto a
target.

```python
driver.find_text("Card").swipe_to(
    driver.find_text("Archive"),
    duration_ms=300,
)
```

**Returns** `None`. `other` is an `Element`; `duration_ms` is an `int`, default
`300`.

## Fields

| Field | Type | Description |
|---|---|---|
| `element.center` | `{"x", "y"}` | Tap point at the element's center. |
| `element.bbox` | `{"x", "y", "width", "height"}` | Bounding box, in pixels. |
| `element.text` | `str \| None` | Recognized text, if any. |
| `element.confidence` | `float` | Match confidence, `0`–`1`. |
| `element.source` | `"ocr" \| "vlm"` | Whether it was found by its text or by describing it. |

<Note>
  [`driver.find_text()`](/driver/reference#driver-find_text) returns `None` on a
  miss, so guard the result before acting.
  [`driver.find()`](/driver/reference#driver-find) raises `ElementNotFoundError`
  instead.
</Note>
