Use a screenshot to save, display, or debug the exact screen image. The result
is a PNG.

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone screenshot --out screen.png
    ```

    The default path is `screenshot.png`. The CLI overwrites an existing output
    file without confirmation.
  </Tab>

  <Tab title="Python SDK">
    ```python
    picture = driver.screenshot()
    with open("screen.png", "wb") as output:
        output.write(picture)
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    picture, err := driver.Screenshot()
    if err != nil {
        log.Fatal(err)
    }
    if err := os.WriteFile("screen.png", picture, 0o600); err != nil {
        log.Fatal(err)
    }
    ```
  </Tab>
</Tabs>

`screenshot` maps to DCP `Screen.screenshot`; it is not a REST operation.

## Picture or structured screen?

- Use **screenshot** for the pixels as PNG data.
- Use [**observe**](/driver/observe) for recognized text, icons, dimensions,
  and a queryable snapshot.

<Tip>
  Capture a screenshot when a step fails. It shows the exact state your
  automation encountered.
</Tip>
