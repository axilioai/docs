The **driver** is what [`client.session()`](/driver/client) hands you inside a
session. It's the object every action runs on — finding, tapping, typing,
swiping, and reading the screen. Methods that locate something return an
[`Element`](/driver/element); reading the whole screen returns a
[`Screen`](/driver/screen).

<Info>
  This page is the signature reference. To learn the model — how you chain a
  **find** into an action — start with [How the driver works](/driver/overview)
  and the [Basics](/driver/find).
</Info>

```python
from axilio.platform import Client

with Client().session("android") as driver:
    driver.find_text("Settings").tap()
```

## Finding

### `driver.find_text()`
Find a single on-screen element by its visible text. Returns `None` if nothing
matches, so guard the result before acting (or use
[`driver.wait_for_text()`](#driver-wait_for_text)).

```python
driver.find_text("Sign in", exact=False, ocr_engine="premium")
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `text` | `str` | required | The visible text to match. |
| `exact` | `bool` | `False` | Require the whole label to match, not a substring. |
| `ocr_engine` | `"free" \| "premium"` | session default | Text-reading engine. `premium` handles harder screens. See [Models](/drivers/models). |

**Returns** <code><a href="/driver/element">Element</a> | None</code> — the best match, or `None` if not found.

### `driver.find_all_text()`
Find every on-screen element whose text matches. Handy for lists and feeds. Pass
`contains` for a substring or `pattern` for a regular expression.

```python
for item in driver.find_all_text(contains="Notification"):
    print(item.text)
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `contains` | `str` | `None` | Keep matches that contain this substring. |
| `pattern` | `str` | `None` | Keep matches against this regular expression. |

**Returns** <code>list[<a href="/driver/element">Element</a>]</code> — every match, or an empty list.

### `driver.find()`
Find something by describing it in plain English, for when there's no text to
match (an icon, an image). Runs a [vision-language model](/drivers/models), so it
costs more than [`find_text`](#driver-find_text). Raises `ElementNotFoundError`
if nothing matches.

```python
driver.find(
    query="the heart icon under the photo",
    model="anthropic/claude-haiku-4.5",
)
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `query` | `str` | required | A plain-English description of what to find (keyword-only). |
| `timeout` | `float` | `10.0` | Seconds to wait for the model before giving up. |
| `model` | `str` | session default | A [vision model](/drivers/models) id. |

**Returns** [`Element`](/driver/element). **Raises** `ElementNotFoundError` on a miss —
import it from `axilio.drivers.mobile`.

## Tapping

### `driver.tap()`
Tap an exact point on the screen. To tap something you located, call
[`element.tap()`](/driver/element#element-tap) instead.

```python
driver.tap({"x": 540, "y": 1180})
```

**Returns** `None`. `coords` is a `{"x": int, "y": int}` dict.

### `driver.long_press()`
Press and hold an exact point, for example to open a context menu.

```python
driver.long_press({"x": 540, "y": 1180}, duration_ms=1500)
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `coords` | `dict` | required | `{"x": int, "y": int}` screen coordinates. |
| `duration_ms` | `int` | `800` | How long to hold, in milliseconds. |

**Returns** `None`.

## Typing

### `driver.type_text()`
Type into the field that's already selected. To tap a field and type in one call,
use [`element.type_into()`](/driver/element#element-type_into). To press Enter
(submit / search), use [`driver.key_press()`](#driver-key_press).

```python
driver.type_text("hello")
```

**Returns** `None`.

## Swiping

### `driver.swipe()`
Swipe between two points. This is also how you scroll — swipe **up** (end higher
than start) to move down a list. To swipe from one located element to another, use
[`element.swipe_to()`](/driver/element#element-swipe_to).

```python
driver.swipe(
    {"x": 540, "y": 1600},
    {"x": 540, "y": 400},
    duration_ms=300,
)
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `start` | `dict` | required | `{"x": int, "y": int}` where the swipe begins. |
| `end` | `dict` | required | `{"x": int, "y": int}` where it ends. |
| `duration_ms` | `int` | `300` | Duration of the swipe, in milliseconds. |

**Returns** `None`.

## Buttons

### `driver.key_press()`
Press a named key. Today that's [`Key.ENTER`](/driver/key) — submit a form or fire
the on-screen keyboard's Go / Search.

```python
from axilio.drivers.mobile import Key

driver.key_press(Key.ENTER)
```

**Returns** `None`. `key` is a string; see [`Key`](/driver/key) for the constants.

## Waiting

### `driver.wait_for_text()`
Wait until the text appears, then return it. The reliable alternative to a fixed
pause. Raises `TimeoutError` if it never appears.

```python
driver.wait_for_text("Confirmed", timeout=30).tap()
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `text` | `str` | required | The visible text to wait for. |
| `timeout` | `int` | `10` | Seconds to wait before giving up. |

**Returns** [`Element`](/driver/element). **Raises** `TimeoutError` — import it from
`axilio.drivers.mobile`.

### `driver.wait_until_gone()`
Wait until the text disappears. Handy for loading spinners. Raises `TimeoutError`
if it's still there when time runs out.

```python
driver.wait_until_gone("Loading", timeout=15)
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `text` | `str` | required | The visible text to wait to disappear. |
| `timeout` | `int` | `10` | Seconds to wait before giving up. |

**Returns** `None`. **Raises** `TimeoutError`.

### `driver.wait_for()`
Poll the screen until your own predicate is satisfied, then return the matching
[`Screen`](/driver/screen). Raises `TimeoutError` if it never passes.

```python
screen = driver.wait_for(lambda s: s.find_text("Done") is not None)
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `predicate` | `(Screen) -> object` | required | Called with each [`Screen`](/driver/screen); a truthy return ends the wait. |
| `timeout` | `float` | `10.0` | Seconds to wait before giving up. |

**Returns** [`Screen`](/driver/screen). **Raises** `TimeoutError`.

## Reading the screen

### `driver.observe()`
Read everything on the screen at once — all text and icons — as a queryable
snapshot you can search without going back to the phone.

```python
screen = driver.observe()
prices = screen.find_all_text(pattern=r"\$\d+\.\d{2}")
```

**Returns** [`Screen`](/driver/screen).

### `driver.screenshot()`
Take a picture of the screen as PNG image data — to save, log, or debug a run.

```python
picture = driver.screenshot()
open("screen.png", "wb").write(picture)
```

**Returns** `bytes` — raw PNG data.
