`Key` holds the named-key constants for
[`driver.key_press()`](/driver/reference#driver-key_press).

```python
from axilio.drivers.mobile import Key

driver.key_press(Key.ENTER)
```

## Constants

| Constant | Value | What it does |
|---|---|---|
| `Key.ENTER` | `"enter"` | Submit a form, or fire the on-screen keyboard's Go / Search action. |

<Note>
  Enter is the only named key today. The set grows one entry at a time, as real
  needs appear. To type characters (rather than press a key), use
  [`driver.type_text()`](/driver/reference#driver-type_text) or
  [`element.type_into()`](/driver/element#element-type_into).
</Note>
