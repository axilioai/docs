The current named-key set contains only Enter.

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone key enter
    ```
  </Tab>

  <Tab title="Python SDK">
    ```python
    from axilio.drivers.mobile import Key

    driver.key_press(Key.ENTER)
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    if err := driver.KeyPress(mobile.KeyEnter); err != nil {
        log.Fatal(err)
    }
    ```
  </Tab>
</Tabs>

| Interface | Constant or value |
| --- | --- |
| CLI | `enter` |
| Python | `Key.ENTER` (`"enter"`) |
| Go | `mobile.KeyEnter` (`"enter"`) |

Use Enter to submit a form or trigger the on-screen keyboard's **Go** or
**Search** action. To enter characters, use [Type](/driver/type).

This action maps to DCP `Keyboard.keyPress`; it is not a REST operation.
