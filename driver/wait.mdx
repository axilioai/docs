Apps take time to load and change. Every [locator](/driver/locator) action
already waits up to 5 seconds for its target, so most steps need no separate
wait. Wait explicitly when you need longer, or when you want to hold until
something appears or disappears without acting on it.

## Wait for text to appear

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone wait-for "Welcome" --timeout 30s -o json
    ```

    Add `--exact` for a case-sensitive exact match. A timeout returns exit
    status `5`.
  </Tab>

  <Tab title="Python SDK">
    ```python
    welcome = driver.get_by_text("Welcome")
    welcome.wait_for(timeout=30)
    welcome.tap()
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    welcome := driver.GetByText("Welcome")
    if _, err := welcome.WaitFor(mobile.StateVisible, mobile.WithTimeout(30*time.Second)); err != nil {
        log.Fatal(err)
    }
    if _, err := welcome.Tap(); err != nil {
        log.Fatal(err)
    }
    ```
  </Tab>
</Tabs>

## Wait for text to disappear

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone wait-for "Loading" --gone --timeout 30s
    ```
  </Tab>

  <Tab title="Python SDK">
    ```python
    driver.get_by_text("Loading").wait_for(state="hidden", timeout=30)
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    if _, err := driver.GetByText("Loading").WaitFor(mobile.StateHidden, mobile.WithTimeout(30*time.Second)); err != nil {
        log.Fatal(err)
    }
    ```
  </Tab>
</Tabs>

A wait can last up to 60 seconds per call. When the time runs out, Python raises
`ActionTimeoutError` (also a built-in `TimeoutError`) and Go returns an error that
`mobile.IsActionTimeout` matches. Any locator works here, including a
description: `driver.locator(query="the order confirmation").wait_for()`.

## Wait for a custom condition

For a condition a locator can't express, observe the screen in a loop:

<Tabs sync={false}>
  <Tab title="Python SDK">
    ```python
    import time

    deadline = time.monotonic() + 30
    while driver.observe().find_text("Done") is None:
        if time.monotonic() > deadline:
            raise TimeoutError("Done never appeared")
        time.sleep(0.3)
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    deadline := time.Now().Add(30 * time.Second)
    for {
        screen, err := driver.Observe()
        if err != nil {
            log.Fatal(err)
        }
        if screen.FindText("Done", false) != nil {
            break
        }
        if time.Now().After(deadline) {
            log.Fatal("Done never appeared")
        }
        time.Sleep(300 * time.Millisecond)
    }
    ```
  </Tab>
</Tabs>

Locator waits run on the phone side as one DCP `Locator.waitFor` call, so they
continue as soon as the screen is ready. The custom loop calls `Screen.observe`
each time. Neither is a REST operation.
