Apps take time to load and change. Wait for the state you expect before acting.

## Wait for text to appear

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone wait-for "Welcome" --timeout 30s -o json
    ```

    Add `--exact` for a case-sensitive exact match. A timeout returns exit
    status `5`.
  </Tab>

  <Tab title="Python SDK">
    ```python
    welcome = driver.wait_for_text(
        "Welcome",
        timeout=30,
        poll_ms=300,
    )
    welcome.tap()
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    welcome, err := driver.WaitForText("Welcome", 30*time.Second, false)
    if err != nil {
        log.Fatal(err)
    }
    if err := welcome.Tap(); err != nil {
        log.Fatal(err)
    }
    ```
  </Tab>
</Tabs>

## Wait for text to disappear

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone wait-for "Loading" --gone --timeout 30s
    ```
  </Tab>

  <Tab title="Python SDK">
    ```python
    driver.wait_until_gone("Loading", timeout=30, poll_ms=300)
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    if err := driver.WaitUntilGone("Loading", 30*time.Second, false); err != nil {
        log.Fatal(err)
    }
    ```
  </Tab>
</Tabs>

Python and Go also accept OCR call options for these helpers. The CLI `wait-for`
command does not expose an OCR-engine flag.

## Wait for a custom condition

The SDKs can poll until a predicate accepts the observed screen:

<Tabs sync={false}>
  <Tab title="Python SDK">
    ```python
    screen = driver.wait_for(
        lambda current: current.find_text("Done") is not None,
        timeout=30,
        poll_ms=300,
    )
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    screen, err := driver.WaitFor(func(current mobile.Screen) bool {
        return current.FindText("Done", false) != nil
    }, 30*time.Second)
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(screen.Hash)
    ```
  </Tab>
</Tabs>

Wait helpers repeatedly call DCP `Screen.observe` and evaluate the match in the
client. They are not REST operations. Prefer them to a fixed sleep because they
continue as soon as the screen is ready.
