`observe` returns a `Screen`: one snapshot of recognized text, icons,
dimensions, hash, and capture time. Local screen queries do not make another
device or inference request.

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone observe -o json > screen.json
    jq '.texts[] | select(.text | contains("Sign in"))' screen.json
    ```
  </Tab>

  <Tab title="Python SDK">
    ```python
    screen = driver.observe()
    row = screen.find_text("Sign in")
    prices = screen.find_all_text(pattern=r"\$\d+\.\d{2}")
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    screen, err := driver.Observe()
    if err != nil {
        log.Fatal(err)
    }
    row := screen.FindText("Sign in", false)
    if row != nil {
        fmt.Println(row.Text)
    }
    prices, err := screen.FindAllText("", `\$\d+\.\d{2}`)
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(len(prices))
    ```
  </Tab>

</Tabs>

## Find one text element

Python `screen.find_text(text, exact=False)` and Go
`screen.FindText(text, exact)` return the first matching OCR element or an empty
result. A non-exact match is a case-insensitive substring; an exact match is
case-sensitive.

## Find all text elements

Python `screen.find_all_text(contains=..., pattern=...)` and Go
`screen.FindAllText(contains, pattern)` return every match. Choose either a
substring or a regular expression, not both. With neither criterion, the
method returns all recognized text.

## Fields

| Python | Go | Description |
| --- | --- | --- |
| `screen.texts` | `screen.Texts` | Recognized text elements. |
| `screen.icons` | `screen.Icons` | Detected icons with geometry and confidence. |
| `screen.width`, `screen.height` | `screen.Width`, `screen.Height` | Screen dimensions in pixels. |
| `screen.captured_at` | `screen.CapturedAt` | When the snapshot was captured. |
| `screen.hash` | `screen.Hash` | Content hash for comparing snapshots. |
