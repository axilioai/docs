Type into whatever you [found](/driver/find). [`type_into`](/driver/element#element-type_into) taps the field first,
then types:

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone tap --query "the Search field"
    axilio phone type "axilio"
    ```
  </Tab>

  <Tab title="Python SDK">
    ```python
    driver.find_text("Search").type_into("axilio")
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    search, err := driver.FindText("Search", false)
    if err != nil {
        log.Fatal(err)
    }
    if search == nil {
        log.Fatal("Search not found")
    }
    if err := search.TypeInto("axilio"); err != nil {
        log.Fatal(err)
    }
    ```
  </Tab>
</Tabs>

## Type into the current field

If a field is already selected, type straight into it:

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone type "hello"
    ```
  </Tab>

  <Tab title="Python SDK">
    ```python
    driver.type_text("hello")
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    if err := driver.TypeText("hello"); err != nil {
        log.Fatal(err)
    }
    ```
  </Tab>
</Tabs>

Typing uses the device-control WebSocket and is not a REST operation.

<Note>
  This types text. To press Enter (submit / search), use [Keys](/driver/buttons).
</Note>
