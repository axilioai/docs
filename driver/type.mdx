Focus a field, then type into it. SDK element helpers combine those two steps.

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone tap --query "the Search field"
    axilio phone type "agentic infrastructure"
    ```
  </Tab>

  <Tab title="Python SDK">
    ```python
    field = driver.wait_for_text("Search")
    field.type_into("agentic infrastructure")
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    field, err := driver.WaitForText("Search", 10*time.Second, false)
    if err != nil {
        log.Fatal(err)
    }
    if err := field.TypeInto("agentic infrastructure"); err != nil {
        log.Fatal(err)
    }
    ```
  </Tab>
</Tabs>

If the field is already focused, type directly:

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone type "hello"
    ```
  </Tab>

  <Tab title="Python SDK">
    ```python
    driver.type_text("hello")
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    if err := driver.TypeText("hello"); err != nil {
        log.Fatal(err)
    }
    ```
  </Tab>
</Tabs>

Text uses a US-layout keyboard, and one request is limited to 4,096 UTF-8
bytes. The phone types printable ASCII. It skips unsupported characters,
including emoji, when the request is otherwise within the limit. To submit a
form or trigger the keyboard's **Go** or **Search** action, press
[Enter](/driver/buttons) after typing.

Typing uses DCP `Keyboard.typeText`; it is not a REST operation.
