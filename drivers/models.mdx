**Argus** is Axilio's vision model, and it is how the driver sees the screen.
It runs two families of models. The **Axilio models** read text, icons, and
layout for `find_text` and `observe`. The **vision-language models** understand
a description for `find(query=...)`. The public catalog lists both families
with live pricing.

<Tabs sync={false}>
  <Tab title="CLI">
    The CLI does not have a model-catalog command. Use the public REST
    operation, then pass the chosen engine or model to `axilio phone`.
  </Tab>

  <Tab title="REST API">
    REST API References:

    - [**Models: list**](/api-reference/argus/list-models): `GET /api/v1/models`

    ```bash
    curl --silent --show-error --fail-with-body \
      https://argus.axilio.ai/api/v1/models
    ```

    The catalog is public; this request does not need an API key.
  </Tab>
</Tabs>

<Note>
  The Python and Go clients for the Argus API are being regenerated for its
  new operations. Until that SDK release, call the REST operations on this page
  directly.
</Note>

## Axilio models

The Axilio line comes in two tiers: **Lite** is free, and **Pro** reads harder
screens such as small fonts and dense layouts for a per-call price. You do not
pass these model IDs to the driver. Pick the tier with an OCR-engine option:

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone observe --ocr-engine premium
    axilio phone find-all-text "Sign in" --ocr-engine premium
    ```

    `phone find-text` and `phone wait-for` use their default OCR engine and do
    not accept an engine override.
  </Tab>

  <Tab title="Python SDK">
    ```python
    driver.find_text("Sign in", ocr_engine="premium")  # Pro
    driver.find_text("Sign in")                        # Lite, the default
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    element, err := driver.FindText(
        "Sign in",
        false,
        mobile.WithOCREngine("premium"),
    )
    if err != nil {
        log.Fatal(err)
    }
    if element == nil {
        log.Fatal("Sign in is not visible")
    }
    fmt.Println(element.Center)
    ```
  </Tab>
</Tabs>

To use a tier for a whole SDK driver instead of every call, set it once:

<Tabs sync={false}>
  <Tab title="Python SDK">
    ```python
    with client.session(
        "android",
        phone_id="ph_123",
        default_ocr_engine="premium",
    ) as driver:
        driver.find_text("Sign in")  # Pro, no per-call option needed
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    driver := mobile.ConnectRemote(
        controlURL,
        mobile.WithDefaultOCREngine("premium"),
    )
    defer driver.Close()
    ```
  </Tab>
</Tabs>

The IDs below are what you see on [usage rows](/usage/overview) and in the
pricing list:

| Model id | What it is | How you get it |
| --- | --- | --- |
| `axilio/argus-detect-1` | Icon and element detection | Included in every screen read |
| `axilio/argus-ocr-lite-1` | Text reading, free tier | `ocr_engine="free"` on a text-only read |
| `axilio/argus-ocr-pro-1` | Text reading, premium | `ocr_engine="premium"` on a text-only read |
| `axilio/argus-vision-lite-1` | Text + icons, free tier | The default for `find_text` / `observe` |
| `axilio/argus-vision-pro-1` | Text + icons, premium | `ocr_engine="premium"` |

## Vision-language models

Describing something in plain English, such as `find(query="the heart icon")`,
runs a vision-language model. Pass a catalog ID to choose one:

<Tabs sync={false}>
  <Tab title="CLI">
    ```bash
    axilio phone find "the buy button" \
      --model anthropic/claude-haiku-4.5
    ```
  </Tab>

  <Tab title="Python SDK">
    ```python
    driver.find(
        query="the buy button",
        model="anthropic/claude-haiku-4.5",
    )
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    element, err := driver.Find(
        "the buy button",
        mobile.WithModel("anthropic/claude-haiku-4.5"),
    )
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(element.Center)
    ```
  </Tab>
</Tabs>

Python and Go can also set a driver default:

<Tabs sync={false}>
  <Tab title="Python SDK">
    ```python
    with client.session(
        "android",
        phone_id="ph_123",
        default_model="anthropic/claude-haiku-4.5",
    ) as driver:
        driver.find(query="the buy button")
    ```
  </Tab>

  <Tab title="Go SDK">
    ```go
    driver := mobile.ConnectRemote(
        controlURL,
        mobile.WithDefaultModel("anthropic/claude-haiku-4.5"),
    )
    defer driver.Close()
    ```
  </Tab>
</Tabs>

Leave `model=` off and Argus picks a sensible default. An id that isn't in the
list below is rejected before anything is billed.

## Calling Argus directly

The driver runs Argus for you on the live screen. If you have your own image
or accessibility tree to analyze, call the Argus API directly. It uses the same
models and has one operation per input:

- [**Screenshots: detect**](/api-reference/argus/screenshots-detect) finds
  icons and reads text in an image.
- [**Screenshots: locate**](/api-reference/argus/screenshots-locate) finds a
  described element in an image.
- [**Accessibility trees: locate**](/api-reference/argus/accessibility-trees-locate)
  picks the described node from accessibility tree nodes you send.

See [Call Argus on your own input](/driver/client#call-argus-on-your-own-input)
for examples.
